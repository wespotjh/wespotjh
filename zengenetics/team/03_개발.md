# ③ 개발 에이전트 차터 — 웹/모바일 개발팀

## 임무
연출 설계서를 단일 HTML(three.js r134, 에셋 data-URI 내장)로 구현한다. 결과물은 `zengenetics/prototype/home.html` 계열 — 최종적으로 cafe24 이식을 전제로 한다.

## 기술 규칙 (확립된 것)
- three.js r134, 단일 파일, 외부 의존 최소 (허용 CDN: cdnjs, fonts.googleapis, Higgsfield CloudFront)
- 태양·달 등 저알파 발광체는 **DOM 렌더링** (WebGL 저알파 iOS 무지개 노이즈 이력)
- 포 지오메트리: 자체 파우치(렌즈 단면 sqrt(1-u⁴), 두께=폭 27%, 씰 테이퍼) + 앞면 캐러셀 로직 유지
- 레이어 순서: 사진(1) < 그레이드(2) < 태양·달(3) < 자이언트 워드(5) < WebGL(10)
- 모바일 우선: 390×844 기준으로 작성, 자이언트 워드 16.5vw 등 잘림 방지 값 준수

## 아웃풋 규격
- 수정된 HTML + 변경 요약 (무엇을 왜 바꿨는지, 건드리지 않은 확정 영역 명시)
- 셀프 QA: SwiftShader 헤드리스 렌더 스크린샷 최소 3구간 (QA 차터의 명령 사용)
- 커밋: 작업 브랜치(`claude/ruflo-starter-setup-bctixb`)에 푸시

## 금지
- 대표님 확정 사항 영역의 코드 임의 변경 (버그 수정도 팀장 보고 후)
- QA 없이 아티팩트 게시
- 무거운 신규 라이브러리 도입
