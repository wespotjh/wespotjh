# 젠제네틱스 웹/모바일 개발팀 (에이전트 팀) 운영 규정

> 2026-09-03 대표님 지시로 구축. 광고팀(wespotjh/zengenetics-meta-ads `marketing/team/`)과 같은 골격 — **제작과 검수 분리, 검수 하드 게이트, 팀장 컨펌 없이는 대표님 보고 금지.**
> 프로젝트 전체 맥락: `zengenetics/design-system.md` (디자인 결정 로그) + 이 폴더의 차터.

## 팀 구성 (6명)

| 역할 | 파일 | 한 줄 임무 |
|---|---|---|
| ① 기획(UX) | `01_기획.md` | 페이지·섹션의 목적과 스크롤 내러티브 설계 |
| ② 디자인 | `02_디자인.md` | 비주얼·모션 연출 설계 (NOIR VISION 톤, 3D 렌더 활용) |
| ③ 개발 | `03_개발.md` | 단일 HTML + three.js 구현, cafe24 이식 고려 |
| ④ QA(모바일) | `04_QA.md` | **하드 게이트.** 390×844 실측 검수 + 대표님 확정사항 회귀 차단 |
| ⑤ 컴플라이언스·카피 | `05_컴플라이언스.md` | 문구 심의 게이트 (칼륨 기능성 불가 등) |
| ⑥ 팀장 | `06_팀장.md` | 통합 컨펌, 대표님 보고(아티팩트 게시) 결정 |

## 작업 순서

```
① 기획 → ② 디자인 → ③ 개발 → ④ QA ──REJECT──→ ③ 재작업 (최대 3회)
                          └(병렬)→ ⑤ 컴플라이언스 ─┐
                              QA PASS + 심의 PASS → ⑥ 팀장 컨펌 → 대표님 보고 (아티팩트 갱신)
```

- 대표님 확인 방식: 아티팩트 미리보기(https://claude.ai/code/artifact/247e23e7-41dd-470a-bb36-98ac14fd27b3)를 폰으로 확인 → 번호/한줄 피드백
- 최종 판정은 항상 **대표님 폰** — SwiftShader가 못 잡는 iOS 버그가 존재함을 전 역할이 인지할 것

## 공통 원칙

- 대표님 확정 사항(design-system.md·핸드오프 §6)은 **되돌리지 않는다** — 위반은 QA 즉시 REJECT
- 컴플라이언스 가드레일(아래)은 전 역할 공통, 심의 에이전트가 최종 게이트
- 지어낸 수치 금지 — `[기간 각주]`, `"오늘 [N]명"` 등 플레이스홀더는 플레이스홀더임을 명시
- 산출물·결정은 `zengenetics/design-system.md`에 기록 (프로젝트의 단일 결정 로그)
