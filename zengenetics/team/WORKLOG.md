## B-2. 2026-09-06 추가 지시

- **cafe24 전제** (CLAUDE.md 영구규칙 7번): 상품 등록·조회 / 장바구니 / 주문 / 결제 / 로그인이

- **피그마 연동 요청**: 대표님이 모든 페이지의 텍스트·자간을 직접 고치고 싶어 하심.
  → 조사 결과 **Claude가 우리 HTML을 피그마 파일로 밀어 넣는 경로는 없다.**
  공식 Figma 커넥터는 *피그마 → 코드* 읽기 전용(`get_design_context`·`get_screenshot` 등)이고,
  Figma REST API 도 파일/레이어 생성을 지원하지 않는다.
  실현 가능한 경로는 ①피그마 플러그인 **html.to.design** 으로 아티팩트 URL 임포트(편집 가능 레이어로 들어옴)
  ②페이지 자체에 **인라인 편집 모드**를 넣어 텍스트·자간을 그 자리에서 고치고 저장.
  ①은 피그마가 제2의 진실원장이 되어 되돌리는 작업이 또 필요해진다 — 09-06 유실 사고와 같은 구조.
  **대표님 선택 대기.**
