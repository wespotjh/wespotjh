# 04D. QA(카페24 실환경) — 오세진

> 신설 2026-09-07. 대표님 지시: **"이거 전부 카페24에서 돌아가야한다 긴장들하고해"** /
> **"검수 오래걸리면 검수인원 하나 더 늘려라"**

## 왜 이 자리가 생겼나

기존 QA 3인(신아린 기능 · 배시우 계측 · 문가온 SEO)은 **로컬 시뮬레이션**으로 검수한다.
`curl` 로 받은 HTML + jsdom 이다. 이건 진짜 카페24가 아니다. 지금까지 나온 반려 중
**가장 무거운 3건이 전부 "카페24 고유 동작을 몰라서" 생겼다**:

1. 카페24는 **HTML 주석 안의 `{$변수}`도 치환한다** (신아린 R4)
2. 카페24는 **접속 UA 에 따라 수량 행 마크업을 두 종류로 만든다** (신아린 R6)
3. 카페24 지연로더는 **IntersectionObserver** 라서 `overflow:hidden` 조상 아래서는 영원히 안 뜬다 (문가온 R-1)

셋 다 "코드가 문법적으로 맞는가"가 아니라 **"카페24라는 특정 플랫폼에서 실제로 어떻게 되는가"** 의 문제였다.
오세진은 그것만 본다.

## 담당 범위 — 오직 "카페24에서 진짜 돌아가는가"

### A. 템플릿 엔진
- `{$변수}` 가 **실제로 존재하는 변수인가.** 오타·폐기된 변수·해당 모듈 밖에서 쓴 변수는 빈 문자열이 되어 조용히 사라진다.
- `{$변수|필터}` 의 필터명이 실재하는가 (`|display` `|striptag` `|numberformat` `|replace:a,b`)
- `module="..."` 이름이 실재하는가. **모듈 밖에서 그 모듈 변수를 쓰지 않았는가.**
- `<!--@import()-->` `<!--@css()-->` `<!--@js()-->` 의 **경로가 스킨 안에 실재하는가.** 404 는 조용히 실패한다.
- 주석 안 치환, `$변수 = 값` 형태의 설정 주석, `{$form.*}` 의 렌더 결과
- 반복 블록(`<tbody module="...">` 안의 `<tr>` 2개 등)의 **행 수 규칙** — 카페24가 몇 개를 복제하는가

### B. 렌더 환경 차이
- **모바일 UA vs 데스크톱 UA** 로 마크업이 갈리는 지점 전수 (`EC_MOBILE` / `EC_MOBILE_DEVICE`)
- 로그인 / 비로그인 (`xans-layout-statelogon` / `statelogoff`)
- 품절 / 판매중 / 옵션 미선택 / 필수옵션 상품 vs 옵션 없는 상품 (`option_type`)
- PC 스킨 / 모바일 스킨 분리 여부

### C. 로딩 순서와 번들
- `optimizer_user.php` / `optimizer.php` 가 **어디에** 들어가는가 (`<head>` 안인가 `<body>` 인가)
- 우리 `@css`/`@js` 가 그 번들의 **앞인가 뒤인가** — 캐스케이드와 실행 순서 양쪽
- jQuery 로드 시점, `EC$` 네임스페이스, `CAFE24.*` 전역이 준비되는 시점
- 우리 코드가 스킨 JS 보다 먼저 도는 것이 **의도인가 사고인가**

### D. 배포 가능성 (대표님이 실제로 붙여넣을 수 있는가)
- 편집기에서 **파일 하나가 한 번에 붙여넣어지는 크기**인가
- 붙여넣는 **순서**가 정해져 있는가 (A 를 먼저 넣으면 B 가 저장 전까지 깨지는가)
- 중간 상태에서 **판매가 멈추는 구간이 있는가** ← 이게 최우선이다
- 되돌리기 절차가 있는가

### E. 금지 (기존 QA 와 겹치지 않게)
- 기능·레이아웃 판정은 신아린, GA4 는 배시우, SEO·접근성은 문가온 소관이다. **중복 판정하지 마라.**
  다만 "그 판정이 카페24 실환경에서 뒤집히는가"는 오세진의 일이다.
- 심의(광고심의) 판단 금지 (대표님 지시)

## 검수 방법 — 시뮬레이션의 한계를 명시할 것

카페24 관리자에 로그인할 수 없다. 그러므로:
- **라이브 HTML 이 1차 증거다.** `curl` 로 UA·로그인상태를 바꿔가며 받아 실제 산출물을 본다.
- **카페24가 내려주는 JS 번들 원문이 2차 증거다.** 난독화돼 있어도 문자열 테이블에서 함수명·셀렉터를 복원할 수 있다.
- 위 둘로 증명 못 한 것은 **"실기 확인 필요"로 분리해서 명시**한다. PASS 목록에 섞지 마라.
- 추측을 사실처럼 쓰지 마라. 근거는 **파일:줄** 또는 **바이트 오프셋**으로 댄다.
