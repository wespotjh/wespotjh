### R1 🔴 `screenTotal()` — 매출 10배

**파일·줄** `ds/js/ga4.js:172-176`

**근거 DOM (라이브 캡처 `prd_11.html` 192,997바이트 지점, 페이지에 `#totalPrice` 는 1개뿐)**
```html
<div id="totalPrice" class="totalPrice">
  <strong class="title">총 구매 금액 <span class="qty displaynone">(QUANTITY)</span></strong>
  <span class="total"><strong><em>0</em></strong> (0개)</span>
</div>
```
요소 전체 텍스트 = `"총 구매 금액 (QUANTITY)68,000원 (1개)"` → 숫자만 뽑으면 `"68000"+"1"` = **680001**.

**같은 선택자를 쓰는 근거 — 카페24 자기 스킨을 직접 열어 확인했다.**
`moa/js/product/detail.js:397` 은 난독화돼 있지만 문자열 테이블에
`'#totalPrice .total strong'` 과 `'#totalPrice .total'` 이 그대로 들어 있고,
`document.querySelector('#totalPrice .total')` 를 MutationObserver 로 감시해
`$('#totalPrice .total strong').text()` 를 읽어 무료배송 게이지를 계산한다.
→ **스킨 자신이 금액의 정본으로 쓰는 자리가 `#totalPrice .total strong` 이다.**

**수정**
```js
function screenTotal() {
  var el = document.querySelector('#totalPrice .total strong, #totalPrice .total em');
  var v = n(txt(el));
  return v > 0 ? v : null;   /* 못 읽으면 null → 호출부가 base_price 로 폴백(기존 동작 유지) */
}
```
`.totalPrice`(클래스만)는 **주문서에서 배송비 블록 이름으로 재사용**되므로 제거했다(R4 동일 원인).

**실측 (`out4.json` → `value_check`)**
```
totalText  : "총 구매 금액 (QUANTITY)68,000원 (1개)"      ← 판정서가 지적한 그 상태 그대로
strongText : "68,000원"
add_to_cart: {"value":68000,"value_source":"screen_total",
              "items":[{"price":68000,"quantity":1}]}      ← 680001 이 아니다
```

### R5 🟠 `item_variant` — 수량은 살리고 할인율만 지운다

**파일·줄** `ds/js/ga4.js:131-152`

대괄호를 통째로 지우던 `\[[^\]]*\]` 를 **치환 함수**로 바꿨다.
```js
.replace(/\[([^\]]*)\]/g, function (_m, inner) {
  if (inner.indexOf('%') !== -1) return ' ';                    /* [지금 24%▼] → 통째 제거 */
  return ' ' + inner.replace(/지금|[▲▼◀▶]/g, '') + ' ';         /* [6+3]·[3set]·[생애 첫 1+1] → 살린다 */
})
.replace(/\(\+[^)]*\)/g, '')            /* (+126,000원) 제거 */
.replace(/\d+\s*%\s*할인\s*\|?/g, '')    /* (45%할인 | …) 제거 */
```
`[지금 3+2▼]`(상품 16, 5box)처럼 **%가 없는 프로모션 대괄호**도 놓치지 않도록
`지금`·화살표만 털어내고 알맹이는 남긴다.

**실측 — 라이브 옵션 25종 전수** (`qa_dev/out6.json` → `R5`)

   **`gtag/js` 로더를 두 번 넣지 않았다**(넣으면 page_view 중복 위험).
