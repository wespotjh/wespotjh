# 홈 하단 개편안 — 레퍼런스·구성·3D 설계·작업지시 (2026-09-04)

> 대표님 지시: 히어로 아래 개편 — 멋지게·깔끔하게·웰니스 무드(카피에 "루틴·웰니스" 금지), **3D로 제품 올라오는 부분 특히 신경**.

### R3. AG1 (히어로 아래 전환 흐름의 교과서)
- 출처: [AG1 마케팅 퍼널 케이스 스터디](https://dtcmode.com/products/ag1-case-study) · [Pronto — 2026 DTC 서플리먼트 트렌드](https://blog.prontous.com/trending-supplement-dtc-brands/)

- **버릴 것**: 과밀한 뱃지·언론 로고 나열(깔끔함 훼손), 성분 75종식 정보 과적재, 공격적 구독 강요 톤

## 2. 하단 섹션 구성안 (히어로 피날레 → 푸터)

순서: **피날레 → ①카드 3종(정돈+RRR) → ②3D 박스 쇼케이스(신설·주인공) → ③신뢰 → ④후기 → ⑤클로징 오퍼 → 푸터/고정CTA**

### ① `#products` — 제품 카드 3종 (기존 유지 + 정돈)
- 목적: 히어로에서 만난 세 제품을 "고를 수 있는 물건"으로 정리해 준다.
- 변경: 카드 상단에 RRR 영문 라벨 추가(재검사 보고서 2안을 이 위치로 이동 적용 — 칼륨 RESET / 비타민B RECHARGE / 마그네슘 RECOVER). 취소선 정가·할인 문구는 공홈 대조 완료 전까지 유지하되 오픈 전 확정(재검사 §1).
- 모바일 390: 세로 스택 카드 3장(기존 그대로), 카드 내 라벨→시간대→제품명→포 이미지→가격→버튼.

### ② `#showcase` — 3D 박스 쇼케이스 (신설 · 이번 개편의 주인공)
- 목적: "이 브랜드는 실물이 아름답다"를 3초 안에 몸으로 느끼게 한다 — 스크롤하면 내 손끝에서 박스가 열리고 포가 떠오른다.
- 구조: **sticky 무대(100vh) + 320vh 스크롤 트랙**. 스크롤 진행도에 따라:
  - 0~70%: box20 플립탑이 뒤로 젖혀지며 열림 (24프레임 스크럽, 안쪽 Zengenetics™ 인쇄 노출)
  - 70~100%: 열린 박스 위로 **포(스틱) 1개가 DOM 레이어로 떠오름** (translateY -8vh→-18vh + 페이드인, 세로 스탠딩 — 확정사항 ⑤ 준수) ← 백로그 #1 "박스 열리며 포 등장" 실현
- RRR: 무대 상단에 제품 칩 3개(RESET·RECHARGE·RECOVER). 탭하면 시퀀스 세트 교체(크로스페이드 0.3s, 프레임 인덱스 유지). 기본 = 칼륨 RESET.
- 카피(안): 헤드 "스무 번의 하루를 담았습니다" / 서브 "열어보면 압니다. 하루 한 포의 무게." — 기능성 표현·금지어 없음. 활성 제품 캡션: RESET "오늘 쌓인 것을 내보내는 시간" / RECHARGE "오후를 다시 채우는 시간" / RECOVER "내일로 넘어가는 시간" (시간 은유만, 효능 단정 없음 — 조문규 심의 대상).
- 무드: 밝은 뉴트럴(#FAF8F5 계열) 배경 + 활성 제품 액센트의 5~8% 틴트 그라데이션, 바닥 접지 그림자. 여백 크게.
- 모바일 390: 칩 3개(상단) → 캔버스 330×330(중앙) → 캡션+미니 CTA(하단). 자이언트 워드 "OPEN"을 캔버스 뒤 z-베이스에 12vw로 깔아 히어로 타이포 언어 연장.

### ③ `#trust` — 신뢰 수치 (기존 유지 + 각주 확정 반영)
- 목적: 방금 느낀 감각(예쁘다)을 숫자(팔린다)로 뒷받침한다.
- 변경: "1위 / 올리브영·쿠팡"에 상세페이지와 동일 각주 부착(올리브영 2026.03.22 09~10시 / 쿠팡 2026.07.27~08.25 — 재검사 §1, 대표님 "그대로 써라" 확인 필요). 4.9/26,961/92%는 출처 확정 전까지 현행 유지, 오픈 전 필수 해결 항목.
- 모바일 390: 큰 숫자 3개 가로 1행(넘치면 1+2), 각주는 하단 작은 회색 텍스트.

### ④ `#reviews` — 후기 (trust에서 분리·신설)
- 목적: 숫자 뒤의 실제 목소리를 들려준다 — 다음 섹션의 오퍼를 받아들일 마음을 만든다.
- 구조: 인용 카드 가로 스와이프 2~3장(현행 1개 인용을 확장), "실제 구매 후기 中" 표기 유지, 알파리뷰 연동 예정 영역 명시. 샘플 인용은 연동 전까지 현행 1건만 노출 권장(지어낸 후기 추가 금지).
- 모바일 390: 카드 폭 80vw 가로 스크롤, 스냅.

### ⑤ `#closing` — 클로징 오퍼 (기존 정돈)
- 목적: 부담 없는 첫 행동 하나(체험판 1+1)로 닫는다.
- 변경: benefits 3열은 카드 ①의 RRR과 중복되므로 **한 줄 요약으로 축소**("세 개의 포가 하루의 세 시간을 맡습니다") → 체험판 CTA를 주인공으로. 가격(8,900원)은 공홈 대조 후 확정.
- 모바일 390: 헤드라인 → 한 줄 요약 → 체험판 CTA 카드(전폭) → 푸터. 하단 고정 ctabar 유지.

### 컴플라이언스 자가 체크
- 카피에 "루틴·웰니스" 미사용(전 섹션 검수 완료 — 무드로만 구현) / 칼륨 기능성 표현 없음(시간 은유만) / 1위 표기는 각주 필수 / 후기·평점 임의 생성 없음.

### 성공 기준
대표님이 폰으로 쇼케이스 구간을 두 번 위아래로 문질러 보면(스크럽 왕복) 통과. "오~"가 나오면 합격.

## 3. 3D 연출 상세 설계 — box20_open 스크롤 스크럽

### 방식: three.js 불필요 — 2D 캔버스 프레임 스왑 (Apple 방식)
- 근거 ①: 시퀀스는 **사전 렌더 24프레임**이라 실시간 지오메트리·조명 계산이 필요 없음. `canvas.getContext('2d')` + `drawImage(frames[i])`만으로 Apple AirPods 페이지와 동일 효과.
- 근거 ②: iOS 리스크 회피 — 히어로에서 WebGL 저알파가 iOS 노이즈를 일으켜 태양·달을 DOM으로 뺀 이력(design-system.md 09-03). 2D 캔버스는 해당 버그 계열 없음.
- 근거 ③: 히어로 WebGL 캔버스와 컨텍스트 분리 — 하단은 WebGL 컨텍스트 추가 없이 가볍게(모바일 WebGL 컨텍스트 수 제한 회피).
- 스크럽: `progress = (scrollY - trackTop) / (trackHeight - vh)` → `frame = round(progress/0.7 * 23)` (0~70% 구간), rAF에서 프레임 인덱스 변화 시에만 다시 그림. 포 부상은 70~100% 구간 CSS transform(GPU 합성)으로.

### 에셋 파이프라인 (실측 완료)
- 원본: 900×900 투명 PNG, 프레임당 ~1.3MB → 그대로 사용 시 제품당 31MB. **불가.**
- 웹용: **660×660 WebP(알파, q80)** — 오늘 potassium_box20_open 3프레임 실측: 20~36KB/프레임 → **제품당 24프레임 ≈ 0.7MB, 3제품 ≈ 2.1MB**. 660px = 390 화면에서 표시폭 330px의 레티나 2배(선명), WebP 알파는 현행 전 브라우저 지원(히어로도 이미 WebP 사용 중).
- 절충안: 트래픽 우선 시 520×520 q78(15~25KB/프레임, 제품당 ≈0.5MB)도 가능 — 1차는 660px 권장, QA에서 아이폰 선명도 확인 후 조정.

### 프리로드 전략
1. 초기 로드: **기본 제품(칼륨) 24프레임만** — 섹션이 뷰포트 1.5화면 안에 들어올 때 IntersectionObserver로 시작 (`new Image()` + `img.decode()` 완료 후 스크럽 활성화, 이전엔 frame_0001 정지 이미지 표시).
2. 나머지 2종: 칼륨 로드 완료 후 idle 시점(`requestIdleCallback`)에 순차 백그라운드 로드. 칩 탭 시 미로드 상태면 스피너 0.5s 내 표시 후 완료 시 크로스페이드.
3. 히어로 에셋 로딩과 경합 금지: 히어로 텍스처 로드 완료 이벤트 이후에만 시작.

### 제품 3종 전환
- 3세트 모두 24프레임 동일 규격 → 칩 탭 시 **프레임 인덱스를 유지한 채 배열 포인터만 교체** + 캔버스 위 0.3s 오퍼시티 크로스페이드(이전 프레임을 보조 캔버스에 홀드). 배경 틴트·캡션·RRR 라벨도 동시 트랜지션.
- 떠오르는 포 이미지는 히어로에서 이미 쓰는 각 제품 앞면 렌더 크롭 재사용(추가 용량 0).
