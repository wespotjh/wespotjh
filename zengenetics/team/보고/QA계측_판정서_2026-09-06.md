## 4. REJECT 상세 — 수정 지시 (개발 이도현)

### R1 🔴 `screenTotal()` 이 요소 전체 텍스트를 긁어 매출을 10배로 만든다

**파일** `cafe24-skin/ds/js/ga4.js:97-101`

```js
  function screenTotal() {
    var el = document.querySelector('#totalPrice, .totalPrice');   // ← 98행
    var v = n(txt(el));                                            // ← 99행 여기가 원인
    return v > 0 ? v : null;
  }
```

**무슨 일이 일어나나.** 라이브 `#totalPrice` 의 실제 마크업은 (`product/detail.html:483`)

```html
<div id="totalPrice" class="totalPrice">
  <strong class="title">총 구매 금액 <span class="qty displaynone">(QUANTITY)</span></strong>
  <span class="total"><strong><em>68,000원</em></strong> (1개)</span>
</div>
```

`txt(el)` = `"총 구매 금액 (QUANTITY)68,000원 (1개)"` → `n()` 이 숫자만 뽑으면 `"68000"+"1"` = **`680001`**.

**실측 (`out4.json` → `value_check`)**

```json
{"event":"add_to_cart","value":680001,"value_source":"screen_total",
 "items":[{"item_id":"11","price":34900,"quantity":1}]}
```
화면 총액은 `68,000원`(`#totalPrice .total strong` 텍스트로 확인). 옵션을 고른 **모든** 담기·구매가 이 값으로 나간다. 옵션 선택은 정상 동선이므로 사실상 전량 오염이다.

**수정 지시.** 카페24 스킨 자신이 쓰는 선택자와 동일하게 좁힌다 — `moa/js/product/detail.js` 는 `'#totalPrice .total strong'` 을 관측한다.

```js
  function screenTotal() {
    var el = document.querySelector('#totalPrice .total strong, #totalPrice .total em');
    var v = n(txt(el));
    return v > 0 ? v : null;
  }
```
`.totalPrice`(클래스만) 은 **주문서에서 배송비 블록 이름으로 재사용**되므로 선택자에서 제거할 것(R4와 동일 원인).

**검증 요구**: 상품 11에서 2 box 옵션 선택 → `add_to_cart.value === 68000`, `value_source === "screen_total"`.

### R2 🔴 `view_cart` 가 한 건도 안 나간다 (+ 나가면 1.1조원)

**파일** `cafe24-skin/ds/js/ga4.js:196-222` (핵심 `204`, `210`)

```js
      var row = a.closest ? a.closest('tr, li, .xans-record-') : null;      // ← 204행
      ...
      var pr = n(txt(row.querySelector('.price, td.price, [class*="price"]')));  // ← 210행
```

**(a) 행을 못 찾는다.** 우리 스킨 `order/basket.html:75-77` 의 장바구니 행은

```html
<div module="Order_list">
  <div class="ec-base-prdInfo gCheck">
    <div class="prdBox">
      <div class="thumbnail"><a href="/product/detail.html{$param}">…</a></div>
```
`<tr>` 도 `<li>` 도 아니다. 실측(`out_pages.json` → `basket`):

```json
{"event":"zg_cart_unreadable","link_count":2,"zg_ver":"2.001","send_to":"G-GZHFY596SS"}
```
→ **`view_cart` 발사 0건.** 차터 A-1 위반(이벤트 누락).

**(b) 행을 찾아도 금액이 파괴된다.** 카페24가 반복 단위에 붙이는 `xans-record-` 를 `[module="Order_list"]` 에 부여해 실제 렌더를 재현하면(`out3.json` → `basket_xansrecord`):

```json
{"event":"view_cart","value":1109901424000,
 "items":[{"item_id":"11","item_name":"젠제네틱스 포타슘 칼륨 (20ea)","price":34900349000,"quantity":1},
          {"item_id":"11","item_name":"[칼마비 건강루틴] … SET","price":1075001075000,"quantity":1}]}
```
원인: `[class*="price"]` 가 `<ul class="price">` **전체**에 매칭되고, 그 안에는 상품가·합계가·할인가 3줄이 들어 있다 → 텍스트 `"34,900원 34,900원 -0원"` → `34900349000`.

**수정 지시.**
1. 행 기준점을 마크업에 맞춘다: `a.closest('.ec-base-prdInfo, tr, li, .xans-record-')`
   (템플릿에서 상품 1건 = `.ec-base-prdInfo` 1개가 보장된다)
2. 가격은 **첫 줄의 `<strong>` 하나만** 읽는다:
   `row.querySelector('ul.price > li:first-child strong, ul.price strong')`
   `[class*="price"]` 와이드카드는 삭제할 것.
3. `item_id` 는 `.thumbnail a[href*="product_no="]` 로 한정 (`.prdName a` 는 `product_no` 가 없다 — 실측).
4. 못 읽으면 지금처럼 `zg_cart_unreadable` 유지.

**검증 요구**: `_preview/basket/after.html` 에서 `view_cart.value === 142400`, `items[0].price === 34900`, `items[1].price === 107500`.

### R5 🟠 `item_variant` — 박스 수량은 지우고 할인율은 남긴다

**파일** `cafe24-skin/ds/js/ga4.js:85-93` (핵심 `89`)

```js
    return t.replace(/\[[^\]]*\]/g, '')          /* [지금 24%▼] 제거 */   // ← 89행
            .replace(/\(\+[^)]*\)/g, '')          /* (+33,100원) 제거 */
```

`[...]` 통째 제거가 단품(11·13·16)에서는 맞지만, 세트·이벤트 상품에서는 **정확히 필요한 정보를 지운다.**

| 상품 | 옵션 원문 (라이브) | 지금 나가는 `item_variant` | 나가야 할 값 |
|---|---|---|---|
| 63 | `붓기부스터 [6+3] (45%할인 \| 9주 \| 무료배송) (+126,000원)` | `붓기부스터 (45%할인 \| 9주 \| 무료배송)` | `붓기부스터 6+3` |
| 64 | `🔥BEST🔥 [3+3] (45%할인 \| 60일 \| 무료배송) (+91,100원)` | `BEST (45%할인 \| 60일 \| 무료배송)` | `3+3` |
| 98 | `칼+마+비 [3set] (45%할인 \| 무료배송) (+128,500원)` | `칼+마+비 (45%할인 \| 무료배송)` | `칼+마+비 3set` |
| 71 | `🔥BEST🔥[생애 첫 1+1] 젠제네틱스 붓기파우더 데이팩 2 box (+5,100원)` | `BEST 젠제네틱스 붓기파우더 데이팩 2 box` | `생애 첫 1+1 … 2 box` |

두 방향 모두 틀렸다.
- **추적계획 §3**: *"몇 박스가 팔리는지는 `item_variant` 로 잡는다"* → 세트 상품에서 그 정보가 사라진다.
- **`ga4.js:84` 자기 주석**: *"할인율·가격은 우리가 저장하지 않는다"* → `45%할인` 이 그대로 GA4로 간다. `CLAUDE.md` 규칙 11의 취지에 어긋난다.

**수정 지시.** 대괄호를 통째로 지우지 말고 **할인율 토큰만** 제거한다.

```js
    return t
      .replace(/\[[^\]]*%[^\]]*\]/g, '')        /* [지금 24%▼] 처럼 %가 든 대괄호만 제거 */
      .replace(/\[|\]/g, ' ')                   /* [6+3] → 6+3 (수량 정보는 살린다) */
      .replace(/\(\+[^)]*\)/g, '')              /* (+33,100원) 제거 */
      .replace(/\d+\s*%\s*할인\s*\|?/g, '')      /* (45%할인 | …) 의 할인율 제거 */
      .replace(/[\u{1F300}-\u{1FAFF}\u{2600}-\u{27BF}]/gu, '')
      .replace(/\s+/g, ' ').replace(/\(\s*\|/g,'(').trim();
```

**검증 요구**: 63 → `item_variant` 에 `6+3` 포함 · `%` 문자 **미포함**. 11 → `젠제네틱스 붓기파우더 1 box`(현행 유지).
