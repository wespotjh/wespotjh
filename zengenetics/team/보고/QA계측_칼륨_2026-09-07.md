**재현·수치 (라이브 실측 기반)**

`#prdDetail` 안 `ec-data-src` 상세 이미지 **14장** (jsdom 카운트 확인).
원본 높이 합(1080px 폭, 브리프 §1-1 실측표):

- → 상세 영역의 **7,594px (81.7%) 가 문서 높이에서 사라진다.**

`ga4.js:750`
```js
var h = document.documentElement.scrollHeight - window.innerHeight;
var pct = Math.round((window.pageYOffset / h) * 100);
```
분모 `h` 가 개편 순간 절반 이하로 줄어든다. 결과:

1. **`zg_scroll_depth` 75/90/100 이 원인 없이 급등한다.** 같은 독자가 같은 만큼 읽어도 퍼센트가 다르게 찍힌다.
2. **접힌 상태에서 100% 를 소진한 뒤 「상세 정보 모두 보기」로 펼치면 재발사가 없다.**
   `ga4.js:747` `fired[m] = 1` 은 되돌려지지 않으므로, 펼친 뒤의 실제 열독 깊이는 **영구히 계측 불가**다.
3. `ec-data-src` 지연로더는 뷰포트에 들어온 이미지만 로드한다 → 접힘 상태에서는 대부분 로드조차 되지 않아
   실제 문서 높이는 1,700px보다도 짧을 수 있다. 한 번의 플릭으로 `percent:100` 이 나갈 수 있다.
4. **그런데 `zg_ver` 는 양쪽 다 `2.001` 이다.** GA4에서 두 상태를 나눌 수 없다.

**왜 블로킹인가**

**주의해서 본 것 하나** — `detail.css:949`


### 4-2. 누락 — 붙여야 하는 것 (우선순위 순)

#### N-1. `zg_detail_expand` — 「상세 정보 모두 보기」 펼침 **(필수)**
이번 개편의 핵심 가설은 *"상세를 접으면 CTA 도달이 빨라진다"* 인데, **펼침률 없이는 가설을 검증할 수 없다.**
- 붙일 위치: `ga4.js` §7 스크롤 블록 직전 (`:735` 부근), 위임으로
- 트리거: `e.target.closest('.zg-more')`
- 파라미터: `{ item_id: currentPrdNo(), seconds: 페이지 진입 후 경과초, scroll_pct_at_expand: 펼침 시점 퍼센트 }`
- 발사 규칙: `send()` (페이지당 1회)

```js
/* ga4.js — §7 직전에 추가 */
document.addEventListener('click', function (e) {
  var m = e.target && e.target.closest ? e.target.closest('.zg-more') : null;
  if (!m) return;
  send('zg_detail_expand', { item_id: currentPrdNo() });
}, true);
```

#### N-2. `zg_scroll_depth` 에 `detail_expanded` 파라미터 추가 **(필수 · R-1 과 한 묶음)**
접힘/펼침 상태를 구분하지 않으면 퍼센트 값이 의미를 갖지 못한다.
- 위치: `ga4.js:755` `sendAlways('zg_scroll_depth', {…})` 페이로드
- 추가: `detail_expanded: document.querySelector('.zg-fold.zg-open') ? 1 : 0`
- 함께: `ZG_VER` → `'2.002'` (R-1)

#### N-3. `zg_guide_chip_click` — 바로가기 칩 3개 **(권장)**
「배송·교환/반품」이 실제로 눌리는지 = 상세 안내 니즈의 크기를 재는 유일한 신호.
- 트리거: `e.target.closest('[data-zg-tab]')`
- 파라미터: `{ chip: el.getAttribute('data-zg-tab'), item_id: currentPrdNo() }` (`sendAlways`)

#### N-4. `zg_option_duplicate_tap` — 이미 담긴 카드 재탭 **(권장)**
`ZG_OPT_MODE='multi'` 확정의 부작용(중복 담기 혼선)을 재는 값. 이 수치가 크면 `'single'` 전환 근거가 된다.
- 트리거: `detail-ui.js:271` 의 토스트 분기와 같은 지점. `ga4.js` 단독으로는 잡을 수 없다 →
  **`detail-ui.js` 가 `document.dispatchEvent(new CustomEvent('zg:dupe-tap',{detail:{key:…}}))` 를 쏘고
  `ga4.js` 가 그것만 듣는 방식**을 권한다 (두 파일의 결합을 이벤트 이름 하나로 제한).
- 파라미터: `{ item_id: currentPrdNo(), picked_count: N }`

#### N-5. `zg_option_native_open` — 「옵션을 직접 선택」 버튼 **(선택)**
이 버튼이 눌린다는 것은 카드 UI가 실패했다는 뜻이다. 8종 전개 전 확인 가치가 있다.
- 트리거: `e.target.closest('.zg-opt-native-btn')` · 파라미터 `{ item_id }` · `send()` 1회

#### N-6. 추가상품 선택 — **이번 개편의 회귀가 아닌 기존 공백** (참고)
라이브 추가상품 select 는 `name="addproduct_option_name_63"` 이라 `ga4.js:348` 의 `/^option/` 에 걸리지 않는다.
→ 붓기부스터·비타민B·마그네슘의 **부착률(attach rate)이 지금도 0으로 계측된다.**
`detail-ui.js:455` 가 이미 `li[data-zg-picked="1"]` 훅을 만들어 두었으므로 붙이기는 쉽다.
**이번 반려 사유가 아니다** — 다음 판 개선 권고로 올린다.
