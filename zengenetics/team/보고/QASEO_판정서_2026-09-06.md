### R-3. `<title>` 이 5개 페이지에서 동일하다 — 차터 B-5 위반

```
'젠제네틱스 공식몰'  ×5
  ├─ /                          (홈)
  ├─ /shopinfo/company.html     (브랜드스토리)  ← 🔴 sitemap 에 등재됨. 실제 색인 대상
  ├─ /order/basket.html         (장바구니)
  ├─ /member/login.html         (로그인)
  └─ /order/orderform.html      (주문서)
     + /order/order_result.html (주문완료)
```

나머지 14개 페이지의 title 은 전부 서로 다르다. ✅

**가장 아픈 건 `/shopinfo/company.html`(브랜드스토리)다.**

### R-4. robots.txt — **Googlebot 그룹에 `/order/` `/basket/` `/checkout/` 가 빠져 있다** — 차터 D-13 위반

robots.txt 는 `User-agent` 그룹이 **가장 구체적인 것 하나만** 적용된다.
`Googlebot` 전용 그룹이 있으면 **구글은 `User-agent: *` 를 통째로 무시한다.**

| 경로 | `User-agent: *` | `User-agent: Googlebot` | `User-agent: bingbot` |
|---|---|---|---|
| `/admin` | ✅ 차단 | ✅ 차단 | ✅ 차단 |
| `/member/` | ✅ 차단 | ✅ 차단 | ✅ 차단 |
| `/myshop/` | ✅ 차단 | ✅ 차단 | ✅ 차단 |
| **`/order/`** | ✅ 차단 | **🔴 없음** | **🔴 없음** |
| **`/basket/`** | ✅ 차단 | **🔴 없음** | **🔴 없음** |
| **`/checkout/`** | ✅ 차단 | **🔴 없음** | **🔴 없음** |
| `/login/` | ✅ 차단 | 🔴 없음 (단 실제 로그인은 `/member/` 하위라 실질 차단됨) | 🔴 없음 |
| 상품 경로 `/product/` | ✅ 안 막음 | ✅ 안 막음 | ✅ 안 막음 |

→ **구글은 지금 `/order/basket.html` · `/order/orderform.html` · `/order/order_result.html` 을 마음껏 크롤할 수 있다.**
셋 다 title 이 `젠제네틱스 공식몰`, description·og 도 홈과 동일 → 얇은 중복 페이지가 크롤 예산을 먹는다.

차터 D-13 요구("`/order/ /basket/ /login/ /member/` 를 막고 상품 경로는 안 막는가")를 **Googlebot 그룹이 충족하지 못한다.**
상품 경로가 안 막혀 있는 부분은 3개 그룹 전부 정상이다. ✅

부수 지적: `Sitemap:` 선언이 `User-agent: bingbot` 그룹 안에 들어가 있다. 규격상 그룹과 무관하게 읽히므로 동작에는 문제 없으나, 파일 맨 위로 올리는 것이 표준이다.

### R-5. 상품 이미지 `alt` 가 비어 있다 — 차터 B-7 위반

상품페이지에서 **실제 상품 이미지에 `alt=""`** 가 들어간다. 장식 아이콘이 아니라 상품 사진이다.

## 5. 404 링크 사냥 — `surl/P/*` 전수 스캔

`surl/P/1` ~ `surl/P/130` **130개 전부 실제 상태코드를 찍었다.**

**살아 있는 번호 = 14개뿐이다:**

```
11  13  16  34  60  61  62  63  64  71  91  93  96  98
```

**나머지 116개는 전부 HTTP 404.** 여기에 `101` 이 포함된다.

```
surl/P/101 → 404   ← GA4 30일 174세션이 들어온 그 경로. 여전히 404다.
surl/P/102 → 404
surl/P/105 → 404
surl/P/110 → 404
surl/P/120 → 404
```

**`surl/P/101` 은 오늘 기준으로도 여전히 404다.** 아직 아무것도 고쳐지지 않았다.

- 저장소 전체(`zengenetics-meta-ads`, `wespotjh`) 를 grep 했으나 **`surl/P/101` 을 쓰는 소재·링크가 우리 저장소에는 없다.**
  → 메타 광고 소재 URL, 인플루언서 링크, 네이버/카카오 등 **외부에 박힌 링크**일 가능성이 높다. (§7 대표님 조치 목록)
- 살아 있는 surl 페이지는 전부 **canonical 이 `/product/…/N/` 클린 URL을 정확히 지목**한다 ✅
  (`surl/P/11` → `canonical=/product/젠제네틱스-포타슘-칼륨-20ea/11/`) — 중복 색인 위험 없음. 잘 돼 있다.

sitemap 대비 누락: sitemap 에 없는 살아 있는 상품 = **34, 91, 93, 96**
- 34 = `noindex` 처리됨 → 의도된 것. 정상
- 91, 93, 96 = noindex 없음 → R-2
