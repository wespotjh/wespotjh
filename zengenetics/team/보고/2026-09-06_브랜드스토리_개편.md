## 9. 기술 제약 준수

- three.js / WebGL / canvas **0건** — DOM+CSS만. cafe24 이식 가능
- 파일 1행 아티팩트 래퍼(`<!doctype html>…<body>`) **원문 그대로 보존**
- 외부 리소스는 `fonts.googleapis.com` 스타일시트(+`fonts.gstatic.com` preconnect)뿐. 이미지 전부 data-URI 인라인
- 사진 주입 방식은 **기존 구조를 그대로 따랐다**: `window.__MAP__`(지도) / `window.__PHOTO__`(사진) 객체를 한 `<script>` 로 두고, 아래 스크립트가 `MAPPING` 표로 `<img id="ph-*">` 에 `src` 를 넣는다. 데이터 라인은 JSON 파싱→키 갱신→재직렬화로 다뤘고, base64 문자열은 어디에도 출력하지 않았다.
- 다크모드 토큰 3벌(`:root` / `prefers-color-scheme` / `[data-theme="dark"]`) 유지

## 10. 못 지킨 것 · 남는 것

1. **폰트 로딩을 실제로 확인하지 못했다.** 샌드박스가 `fonts.googleapis.com` 을 막아 스크린샷의 서체는 시스템 폴백이다. 실제 아티팩트에서는 Noto Serif KR / IBM Plex Sans KR 로 렌더된다 — republish 후 대표님 화면에서 한 번 눈으로 봐 주셔야 한다.
2. **문서 제목이 바뀌었다**(§1). republish 시 아티팩트 이름이 「하루를 고르게」로 바뀌므로 `site/README.md` 표기도 같이 고쳐야 한다. 되돌리길 원하시면 파일 2행 `<title>` 한 줄만 고치면 된다.
3. **커버 사진 5장은 스톡 무드컷**이다. 실제 촬영본이 생기면 `__PHOTO__` 의 `zen0`·`zen1`·`zen3`·`zen6`·`zen9` 다섯 키만 갈아 끼우면 된다.
4. **커밋·푸시·republish 는 하지 않았다** (지시대로 메인 세션이 처리). 규칙상 ①파일 수정 ②동일 URL republish ③커밋·푸시 셋이 다 끝나야 작업이 끝난다 — ①만 완료 상태다.
