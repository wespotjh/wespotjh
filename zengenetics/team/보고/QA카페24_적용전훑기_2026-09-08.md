### 1-2. ★ 의도 밖 변경 — 차단 사유

**모든 moa 레이아웃 페이지(홈·카테고리·장바구니·로그인·상세 3, 데스크톱 UA 도 동일)에서 `</head>` 직후가 이렇다:**

```
라이브  : …</title></head>⏎<body id="main">    <div class="mpopup …      (홈)
        : …</title></head>⏎<body>    <div class="top-banner …           (그 외)
작업본  : …</title></head><body><p>⏎웅 다⏎</p>⏎    <div class="mpopup …  (홈 — id="main" 없음)
        : …</title></head><body><p>⏎웅 다⏎</p>⏎    <div class="top-banner …
```

- **무엇이 일어났나.** `</head>` 와 레이아웃의 `<body>` 사이에 텍스트 `웅 다` 가 들어가 있다. 카페24가 문서를 정규화하면서 그 텍스트를 `<body><p>…</p>` 로 감쌌고, 레이아웃 자신의 `<body id="main">`(`layout/basic/main.html`) / `<body>`(`layout.html:4`) 는 **버려졌다**. 정규화가 아니었다면 `</head>⏎웅 다⏎<body id="main">` 로 보였을 것이다.
- **영향 ①** 전 페이지 최상단에 문단 하나(글자 "웅 다" + `p` 기본 상하 여백)가 헤더 위에 얹힌다 — 판매를 막진 않지만 **대표님 몰 전체에 오타가 노출**된다.
- **영향 ②** 홈 `id="main"` 소실 — 홈 사용자 CSS 번들에 `#main .header…` 계열 규칙 **37개**(`#main .header{…}`, `#main .header__wrap:not(.m-fixed)…`, 로고·카테고리 링크 색 등)가 있다. 적용하면 **홈 헤더 스타일이 라이브와 달라진다.**
- **어디서 왔나 (근거 있는 추정).** ⑤ `moa/layout/head.html` 은 이번에 붙여넣은 파일 중 유일하게 **끝이 `</head>`** 이고, 두 레이아웃(`main.html`·`layout.html`)이 공통으로 import 한다. 텍스트가 `</head>` **뒤·`<body>` 앞**에 있다는 것은 head.html 꼬리(또는 두 레이아웃 파일 모두의 같은 자리 — 가능성 낮음)를 뜻한다. `웅 다` 는 한글 IME 로 `dnd ek` 를 친 모양 — 편집기에 커서가 있는 채 키가 눌린 사고로 보인다. 시점: 09-06 미리보기 캡처(스크래치 `cafe24/*.html`)에는 **없고**, 오늘 첫 캡처(07:45)부터 **있다**. 저장소 `head.html` 은 64행 3,495 B, 끝 줄 `</head>` 로 깨끗하다.

**고치는 법 (편집기 1분).**
1. 작업본 `moa/layout/head.html` 열기 → 맨 아래로. **64행 `</head>` 뒤에 무엇이든 있으면 전부 삭제** (빈 줄 포함). 저장.
2. 저장 후 파일 크기 **3,495 B** · 끝 줄 `</head>` 확인.
3. 거기에 없으면 `layout/basic/layout.html` 과 `layout/basic/main.html` 의 `<!--@import(/moa/layout/head.html)-->` 와 `<body…>` 사이를 본다.
4. **내게 알려 주시면 미리보기를 다시 받아 `웅 다` 0건 · 홈 `<body id="main">` 복원을 확인하고 GO 를 낸다.** (곧바로 확인: 미리보기 홈 소스보기 → `웅 다` 검색 0건)
