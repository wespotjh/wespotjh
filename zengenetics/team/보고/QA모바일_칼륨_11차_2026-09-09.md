## 3. 「추가」 칩 · 본품/추가 구분 (지시 2·3) — **채택안 유지 권고**

### 3-1. 칩 수치

| 항목 | 실측 | 판정 |
|---|---|---|
| 칩 글자색 | `rgb(95,98,108)` | |
| 칩 배경 | `rgb(251,250,248)` | 행이 흰색이 되며 **칩만 옅은 톤**으로 남는다 |
| 칩 테두리 | `1px rgb(233,232,228)` | 유지 |
| **칩 글자 ↔ 행 배경(흰색)** | **6.09 : 1** | **AA 통과**(4.5:1) — 개발 보고 6.0:1 재현 |
| 칩 글자 ↔ 칩 배경 | 5.83 : 1 | AA 통과 |
| 칩 배경 ↔ 행 배경 | 1.04 : 1 | 칩 면(面)은 거의 안 보이지만 **테두리가 윤곽을 만든다** |

칩 자체는 죽지 않는다. `content:"추가"` 도 정상 렌더.

### 3-2. 구분 — 내가 직접 캡처해 눈으로 확인했다

세 판(10차 / 11차 채택안 / 대안)을 같은 조건에서 `#totalProducts` 만 캡처해 비교했다.

- **채택안(11차)**: 세 행 모두 흰색, 각 추가상품 행 앞에 「추가」 칩, 행 사이 1px 구분선. **구분은 된다.** 「기본 상품처럼 흰 배경 + [추가] 태그 유지」라는 지시에 정확히 부합한다.
- **대안(레일만 복원)**: 배경은 흰색이지만 **왼쪽에 회색 세로 막대가 남는다.** 이것은 대표님이 「색깔이 다른 구성처럼 보인다」고 지적한 신호의 절반을 되살리는 것이다.

**판정: 채택안이 낫다. 대안은 권고하지 않는다.** 이유 ① 지시가 「기본 상품처럼」이었고 레일은 그 반대 방향이다 ② 구분 정보는 이미 칩(6.09:1)과 구분선 두 개가 하고 있다 ③ 레일은 색으로 계층을 만드는 장치라, 지운 배경 톤과 같은 성격이다.
만약 실기에서 구분이 약하다고 느끼시면 **레일 복원이 아니라 칩 강화**(테두리·글자 톤) 방향을 권고한다 — 그 경우 새 판으로 다시 제출해야 한다. 대안본은 기하가 채택안과 동일함을 확인했으므로(§3-3) 대표님이 고르시면 그대로 쓸 수 있다.

### 3-3. 대안본 기하

390px 에서 **채택안과 기하 완전 동일**(폭 134 · `− N +` · 겹침 0 · 여백 20 · 중심Δ 1). 배경 흰색 + `inset 3px` 레일만 다르다. CSS 1줄 차이라는 개발 설명이 맞다.
