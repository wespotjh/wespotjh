## 6. 하네스 H9 — 표본 반전 + **이 검사가 그 증상을 잡는가** 판정

내가 파일을 갈아 끼워 `h_home.py` H9 를 직접 돌렸다.

| 먹인 코드 | H9 결과 |
|---|---|
| **4차(무변경)** | H9 15검사 **전부 PASS** (p95 28.5 · 롱태스크 0 · 빈 판 0 · state ready · back.mid 2 · back.top 0). 개발의 음성 대조 2종도 성립: `neg.jank` p95 65.5/long 647 · `neg.late` 빈 판 23 |
| 히어로 가드 1줄 제거 | **`H9.p95` FAIL(61.5)** · **`H9.long` FAIL(875)** · `H9.var.hero` FAIL(변이 생성 불가 감지) |
| 프레임 게이트 제거 | **`H9.late.notReady` FAIL(23)** · `H9.var.blocks` FAIL |
| **3차 코드 통째(hero+blocks)** | **`H9.p95` FAIL(67.9)** · **`H9.state` FAIL** · **`H9.late.notReady` FAIL(23)** · **`H9.late.state` FAIL** |

**판정: H9 는 대표님이 느낀 증상을 실제로 잡는 검사다.** 3차 코드를 먹이면 반려된다 — 즉 이 검사가 4차 이전에 있었다면 894검사 통과가 나오지 않았다. 「버벅」은 `H9.p95`, 「빤짝」은 `H9.late.notReady`/`state` 가 잡는다.

**다만 약점 4가지(P3):**
1. **`H9.p95` 임계 45ms 의 여유가 크지 않다** — 내 실측 3차 61.5~78 / 4차 24~28.5. 더 빠른 러너에서는 3차 결함이 45ms 아래로 내려가 통과할 수 있다. **35ms 로 조이거나, 임계 대신 "가드 제거본 대비 배율" 로 판정**하기를 권고한다.
2. **`H9.long` 은 단독으로는 3차를 못 잡는다** — 3차 실측 625ms(임계 800) 로 PASS 였다. 실제로 잡은 것은 p95 다.
3. **하네스는 DPR 1 로 잰다**(`home.mjs` `deviceScaleFactor:1`). 실기는 DPR 2~3 이고 합성기 부하가 다르다. 내 측정은 DPR2 로 했고 분리가 더 선명했다 → 하네스도 DPR2 권고.
4. `H9.back.*` 은 **안정될 때까지 폴링**해서 최종 상태만 본다 — §2-2 의 되감기(1.2초)는 통과시킨다. "즉시" 를 검사하지는 않는다(현 동작이 3차와 같으므로 지금은 문제 아님).

또한 `jank` 시나리오는 **칼륨 블록만** 스크럽한다. 3번째 블록(내 실측 3차 24.1fps)은 검사 밖 — 같은 원인이라 지금은 무해하나 1블록 커버리지임을 기록한다.

## 7. 지시 위반 판정 — `home-hero.js` 8줄

**ⓐ 측정 결과에 비례하는 최소 수정인가 — 그렇다.**
순증 10줄 중 **기능 코드는 4줄**(`var onStage = true;` / `onStage = rect.bottom > -80;` / `if (!onStage) { pNow = pTarget; return; }` / `var rect` 를 조기 반환 위로 올린 재배치), 나머지 6줄은 근거 수치를 적은 주석이다. rAF 루프·리스너·연출 파라미터·트랙 높이·크로스페이드는 손대지 않았다. §1 의 교차 조합이 **성능 회복 전부가 이 4줄에서 나온다**는 것을 보였으므로, 측정이 지목한 곳을 지목한 만큼만 고쳤다.

**ⓑ 되돌리면 3차로 정확히 복귀하는가 — 그렇다(바이트 단위 확인).**
4차 `home-hero.js` 에서 위 추가분(주석 블록 + `var onStage` + `onScroll` 두 줄 순서 + `frame()` 가드)을 제거한 결과가 3차 파일과 **바이트 동일**했다: 34,919 B, **md5 `071f78c2` = 3차 제출 md5**.

**QA 의견:** 허용 목록을 벗어난 것은 사실이나, ⓐ·ⓑ 가 성립하고 §6 에 미리 밝혔으며 변경이 우리 4파일 안에 머물렀다. 칼륨 7파일·`zg-ga4.js`·이미지 86장 불변도 확인했다. **이 건은 정당하다고 판정한다.** (다음부터는 측정이 허용 목록 밖을 지목하면 **고치기 전에 한 줄 보고**하는 절차를 권고한다.)
