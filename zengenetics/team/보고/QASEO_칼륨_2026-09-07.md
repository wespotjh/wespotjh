## 1. ❌ REJECT 사유 (P0 · 반드시 수정)

### R-1. 상세 내용 색인 소실 — 접기 래퍼가 카페24 lazyload 를 영구 차단한다

| 위치 | 내용 |
|---|---|
| `ds/css/detail.css:772` | `.zg-detail .zg-fold { position: relative; max-height: 1700px; overflow: hidden; }` |
| `ds/css/detail.css:997` | `.zg-detail .zg-fold { max-height: 2200px; }` (≥1024px) |
| `moa/import/product_detail/detail.html:10-13` | `<div class="zg-fold">` 가 `{$product_detail}` 을 감싼다 |
| `ds/js/detail-ui.js:428-432` | 완화책으로 `scroll`/`resize` 이벤트를 쏘지만 **효과 없음** |

**사실 관계 (실측):**

1. 라이브 11번 상세설명은 **`<img ec-data-src="…">` 14장이 전부**다. `src` 없음, `alt` 없음, 텍스트 0자.
   (`#prdDetail`~`#related` 구간 추출 텍스트 = 272자, 전부 알파리뷰 위젯 문구. 상세 본문 텍스트 **0자**)
2. 카페24 optimizer 번들 원문(`/ind-script/optimizer.php…`, offset 623743)에서 로더 구현을 확인했다:
   ```js
   EC$(function() { sAttribute = 'ec-data-src';
       if (EC$('img['+sAttribute+']').length > 0) { CAFE24.lazyload(); } });

   CAFE24.lazyload = function() {
     var oConfig = { rootMargin: '0px 0px 50px 0px', threshold: 0 };
     var placeholder = 'data:image/png;base64,iVBORw0KGgo…';   /* 1×1 투명 PNG */
     EC$('img['+sAttribute+']').attr('src', placeholder);        /* ← 전부 즉시 1×1 로 덮는다 */
     var oIntersection = new IntersectionObserver(…);            /* ← 교차해야만 진짜 src 로 승격 */
   ```
3. **IntersectionObserver 의 교차 사각형은 조상의 클립 사각형과 교집합을 취한다.**
   `overflow:hidden` + `max-height:1700px` 로 잘려나간 자식은 **어떤 스크롤을 해도 `isIntersecting` 이 참이 되지 않는다.**
4. 상세 이미지 14장 합산 높이 ≈ **21,500px**(860px 폭 기준, 브리프 §1-1 실측 높이 합).
   1700px 안에 들어오는 것은 1장 + 2장째 일부 → **약 12장이 영구히 1×1 placeholder 로 굳는다.**
5. `bindFold()` 의 `window.dispatchEvent(new Event('scroll'))`(`detail-ui.js:430`)은
   **IntersectionObserver 에 아무 영향이 없다**(IO 는 스크롤 이벤트 구독이 아니다).
   실사용자는 버튼을 누르면 레이아웃이 바뀌어 IO 가 자동 재평가되므로 정상 동작한다 — **문제는 크롤러다.**

**결과:** Googlebot 은 상세 영역을 *이미지 1장 + 1×1 투명 PNG 13장 + alt 0개 + 텍스트 0자* 로 렌더한다.
→ **이 상품의 설명 콘텐츠 전량이 색인·구글 이미지에서 사라진다.** 개편 전에는 렌더러의 스크롤 시뮬레이션으로
로드되던 것이므로 **명백한 회귀**다.

### R-1 수정안 (붙여넣기용)

`ds/js/detail-ui.js` — IIFE 최상단, **`ready()` 안이 아니라 파싱 시점에 동기 실행**한다.
(스크립트 태그가 body 최후미라 `#prdDetail` 은 이미 파싱돼 있고, `CAFE24.lazyload()` 는 jQuery ready 에서
돌기 때문에 우리가 먼저 이겨야 한다.)

```js
/* ── K-09 SEO 하드가드 (QA 문가온 REJECT R-1) ────────────────────────────
   .zg-fold 는 overflow:hidden 이라 CAFE24.lazyload() 의 IntersectionObserver 가
   접힌 구간의 <img> 와 영원히 교차하지 않는다 → 1×1 placeholder 로 굳어 색인 소실.
   ec-data-src 를 우리가 직접 src 로 승격하고 속성을 지워 로더 대상에서 제외한다.
   성능은 네이티브 loading="lazy" 로 유지한다(네이티브는 마크업의 src 를 지우지 않는다). */
(function unlazyDetailImages() {
  try {
    var host = document.getElementById('prdDetail');
    if (!host) return;
    var h1 = document.querySelector('.prd-name');
    var nm = h1 ? h1.textContent.replace(/\s+/g, ' ').trim() : '';
    var imgs = host.querySelectorAll('.zg-fold img[ec-data-src]');
    for (var i = 0; i < imgs.length; i++) {
      var img = imgs[i], real = img.getAttribute('ec-data-src');
      if (!real) continue;
      img.removeAttribute('ec-data-src');          /* CAFE24.lazyload() 대상에서 제외 */
      img.setAttribute('loading', 'lazy');
      img.setAttribute('decoding', 'async');
      if (!img.getAttribute('alt')) img.setAttribute('alt', nm + ' 상세 이미지 ' + (i + 1));
      img.src = real;
    }
  } catch (e) {}
})();
```

## 5. 구성 카드 role 판정 + 권고 마크업

### 5-1. 판정: **role="radio" 를 쓰지 않았다 → REJECT 사유 아님** ✅

개발이 실제로 넣은 것 (`ds/js/detail-ui.js:202-212`):

```js
cardWrap.setAttribute('role', 'group');
cardWrap.setAttribute('aria-label', '구성 선택');
…
var b = el('button', 'zg-opt');
b.type = 'button';
b.setAttribute('role', 'button');       // <button> 에 중복이나 무해
b.setAttribute('aria-pressed', 'false');
```

대표님 확정 = **「여러 구성 담기」(복수 선택, `ZG_OPT_MODE='multi'`)**.
`role="radio"`(단일 선택)는 **쓰지 않았다.** 브리프가 경고한 의미·동작 불일치는 **발생하지 않았다.**

또한 카드 안에 **눈에 보이는 상태 텍스트**가 들어간다 (`detail-ui.js:548`, `detail.css:389`):
`c._zgState.textContent = '선택됨 · ' + hit.qty + '개'`
→ 버튼의 **접근가능한 이름(accessible name)에 상태가 사실대로 포함**된다. 스크린리더가 거짓말하지 않는다. ✅

키보드·포커스도 통과:
- 카드·칩·「상세 정보 모두 보기」가 전부 **진짜 `<button type="button">`** → Tab 이동·Enter/Space 기본 동작 ✅
- 스킨의 `outline:none` 은 `.review-nav*` 와 `select:focus` 에만 걸려 있고 **일반 button 에는 없다**
  (`ptrv_style.css:522,643` / `prdt_style.css:403` / `ec-base-ui.css:394` / `css/module/product/detail.css:712` 전수 확인)
  → UA 기본 포커스 링 생존 ✅
- native `<select>` 는 `display:none` 이 아니라 클립 유틸(`detail.css:81-89`, `clip-path:inset(50%)`)로 렌더 트리 유지 ✅
- 「옵션을 직접 선택」 토글에 `aria-expanded` 상태 갱신 있음 (`detail-ui.js:245,250-251`) ✅
- 터치 타겟: 카드 `min-height:56px`(`:316`) / 수량 버튼 `44px`(`:426`) / 칩 `min-height:44px`(`:814`) /

### 5-2. 남은 결함 (P1 권고 — 이번 라운드에서 같이 고칠 것)

## 6. `alt` 속성 판정

### 6-1. 회귀 여부: **없음** ✅

- 이번 diff 는 **`<img>` 를 단 한 개도 추가하지 않았다.**(추가 마크업은 div/span/button/h2/p 뿐)
