현재 구조는 **h2 ×3 이 h1 보다 앞**에 와서 스크린리더 제목 탐색에서 h1 이 4번째로 나오고, SEO 상 h1 에 키워드가 없다.

## 2. 홈 `<title>` — 코드로 못 고친다. **관리자 SEO 「메인 페이지」 탭이 정답, 「코드 직접입력」은 금지**

### 2-1. 실측
```
라이브 홈 (PC·모바일 동일):
  <title>젠제네틱스 공식몰</title>            ← @116,393 · 정확히 1개
  canonical https://zengenetics.co.kr/        ← 1개, 자기 자신
  description ① "단일 성분, 빠른 흡수 Zengenetics" (@12,481 · 이긴다)  ② 전역 문구 (@77,639)
  og:title "젠제네틱스 공식몰" · og:description = description ①
index.html:  <title> 0 · <meta> 0 · canonical 0     ← 개편이 title 에 손대지 않는다
head.html:   <title>기본 레이아웃</title>             ← 칼륨 4차에서 15/15 페이지 "출력 0건" 실증(엔진이 치환)
```
**→ 개편 후에도 `젠제네틱스 공식몰` 그대로다.** 3차 판정서 N-1 이 지적한 "홈 title 에 브랜드명 외 키워드 0개"가 유지된다.

### 2-2. 어디서 고치는가
| 경로 | 가부 |
|---|---|
| `index.html` 에 `<title>` 삽입 | ❌ **절대 금지.** 본문 슬롯이라 `<body>` 안에 두 번째 `<title>` 이 생긴다 = **09-06 사고와 같은 클래스** |
| SEO 고급설정 「코드 직접입력」 | ❌ **금지.** 전 페이지 head 에 실려 상품페이지 title 까지 덮는다 — 09-06 사고의 원인 자리 |
| **관리자 › 쇼핑몰 설정 › 검색엔진 최적화(SEO) › 주요 페이지 SEO 태그 › 메인 페이지** | ✅ **정답.** 상품 title 이 `[PRODUCT_NAME] - [MALL_NAME]` 규칙으로 나오는 바로 그 화면. 홈 한 페이지에만 적용되고 `<title>` 개수는 1 을 유지한다 |
