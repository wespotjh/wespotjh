1. **상세페이지 — 작업 완료.** 대표님 제작본(칼륨·비타민B 완료, 마그네슘 시안 확정 진행)을 기준으로 확정. 프로토타입 상세는 폐기하고 스크롤 인터랙션 참고용으로만 보관. → 이후 문구·표기 점검은 조문규가 이어받음
2. **디자인 시스템 문서화** — 상세페이지 실물 기준의 컬러(제품별 액센트: 칼륨 오렌지 / 비타민B 핑크 / 마그네슘 퍼플)·타이포(볼드 고딕, IBM Plex Sans KR 700)·13단 페이지 구조 템플릿을 `design-system.md`에 정리. → 홍시아가 이어받음
3. **홈 히어로 프로토타입(`prototype/home.html`)** — 스크롤 내러티브 "하루" 구조(인트로→아침 비타민B→3PM 인터루드→저녁 칼륨→밤 마그네슘→ALL DAY 피날레), 자이언트 타이포 + 컬러 월드, 실사 6장 크로스페이드, three.js 파우치 3D. → 기획 유나래, 구현 이도현이 이어받음

5. **iOS 버그 수정 이력** — 대표님 아이폰 제보 기반: 태양 무지개 노이즈(WebGL→DOM 이동), 포 옆면 뚫림(불투명 텍스처 크롭) 등 수정 완료. → 실기기 검증 체계는 신아린이 이어받음

## 3. 남은 일과 진행 계획 (우선순위 순)

핵심 축은 **홈페이지의 cafe24 이식**입니다. cafe24 관련 사항은 일반 지식 전제이므로 전 항목 "조사 후 확정"입니다.

1. **홈 프로토타입 확정** — 담당: 유나래(기획 정리)·나윤설(컨펌) / 선행: 대표님 폰 최종 확인. 홈 하단 섹션 마감 포함. 리스크: 확정 전 이식 시작하면 재작업 비용 큼
2. **cafe24 스킨/디자인 모드 조사** — 담당: 이도현 / 선행: cafe24 계정 접근(§4). 스마트디자인 편집 범위, 외부 스크립트(three.js CDN)·커스텀 JS 허용 범위, 이미지 호스팅 용량 확인. 리스크: cafe24가 스크립트를 제한하면 3D 연출 축소판 필요
3. **이식 방식 결정: 스킨 직접 수정 vs 단일 HTML 삽입** — 담당: 이도현(비교안)·나윤설(결정, 대표님 상신) / 선행: 2번 조사 결과. 리스크: home.html 1.4MB(렌더 텍스처 내장) — cafe24 페이지 용량·로딩 정책에 따라 에셋 외부 분리 필요할 수 있음
4. **섹션별 이식 (히어로 → 카드 → 하단 순)** — 담당: 이도현 / 선행: 3번 결정. 각 섹션 이식마다 확정사항 7개 회귀 체크. 리스크: cafe24 기본 CSS/스크립트와 충돌, 모바일 뷰포트 차이
5. **실기기 QA** — 담당: 신아린 / 선행: 4번 각 섹션. 390×844 실측 + **대표님 아이폰 최종 확인 필수**(SwiftShader가 iOS 버그를 못 잡음 — 태양 노이즈가 실제 사례). 컴플라이언스 문구 심의(조문규) 병렬
6. **오픈** — 담당: 나윤설(최종 컨펌·보고) / 선행: QA PASS + 심의 PASS + **대표님 승인(cafe24 실서버 반영은 팀 권한 밖)**
7. (병렬) **마그네슘 26포 확정 시 카드 가격·포수 갱신** — 담당: 이도현 / 선행: 대표님 확정(§4)
8. (병렬) **플레이스홀더 실데이터 교체, 채널 공식 로고 삽입** — 담당: 조문규(표기 심의)·이도현 / 선행: 대표님 자료 제공(§4)
9. (후순위) **브랜드 스토리 페이지 마감, 박스 오픈 3D 연출 배치** — 담당: 유나래·홍시아 / 선행: 홈 오픈 이후

## 4. 대표님 결정 필요 사항

1. **cafe24 계정 접근 방법** — 관리자 접근 권한을 어떤 방식으로 주실지 (이것이 없으면 3번 항목 전체가 못 나갑니다)
2. **마그네슘 26포 확정 여부** — 현재 홈 카드는 "20포 · 37,900원" 표기. 26포 확정 시 가격 포함 알려주시면 즉시 갱신
3. **플레이스홀더 실데이터** — 순위 기간 각주, "오늘 [N]명" 등에 넣을 실제 수치·기준 자료
4. **홈 프로토타입 최종 확정** — 현재 버전으로 이식 착수해도 되는지 폰으로 최종 확인 부탁드립니다
5. **홈에서 Reset·Recharge·Recover 노출 여부** — 상세페이지들이 공통 사용 중인 문구를 홈에도 쓸지
