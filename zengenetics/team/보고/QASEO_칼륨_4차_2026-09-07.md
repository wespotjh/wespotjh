## 4. `media="print" onload=` · `<noscript>` · 크롤러 판정 ✅

```html
<link rel="stylesheet" href="…&display=swap" media="print" onload="this.media='all';this.onload=null;">
<noscript><link rel="stylesheet" href="…&display=swap"></noscript>
```

| 환경 | 동작 | 판정 |
|---|---|---|
| **JS 켜짐 (일반 사용자)** | `media="print"` 로 저우선 비차단 다운로드 → `onload` 에서 `media='all'` 전환 → 적용. `onload=null` 로 재진입 차단 | ✅ |
| **JS 꺼짐** | `onload` 은 **인라인 JS 라 실행되지 않는다** → 본체 링크는 `media="print"` 로 남아 화면에 적용 안 됨. **바로 이 구멍을 `<noscript>` 가 막는다** — 스크립팅 비활성 시 noscript 내용이 파싱돼 평범한 stylesheet 로 적용 | ✅ **폴백 정확히 걸렸다** |
| **이중 요청 위험** | JS 켜짐이면 `<noscript>` 내용은 **DOM 으로 파싱되지 않는다** → 요청 1회 | ✅ |
| **HTML5 유효성** | `<head>` 안 `<noscript>` 는 `<link>`/`<style>`/`<meta>` 만 허용 — 여기 내용은 `<link>` 1개 | ✅ 유효 |
| **크롤러(Googlebot)** | JS 를 실행하므로 전환된다. **설령 실행하지 않아도 색인 영향은 0** — 이유 3가지 ⑴ 웹폰트는 **콘텐츠가 아니다**(DOM 텍스트가 바뀌지 않는다) ⑵ `display=swap` 이라 폰트 도착 여부와 무관하게 폴백으로 **즉시 렌더**되어 텍스트가 사라지는 구간이 없다 ⑶ Archivo/IBM Plex Mono 는 **숫자·라틴 라벨 전용**이고 한글 본문은 자체 호스팅 Pretendard 가 담당한다 | ✅ **색인 영향 0** |
| **렌더 블로킹** | `media="print"` 이므로 CSSOM·렌더를 막지 않는다. `<head>` 배치인데도 LCP 를 늦추지 않는다 | ✅ |

**개발 주석(`:27-30`)의 "head 의 stylesheet 가 뒤에 오는 classic script 실행을 막는다" 는 사실이다.**
비차단 처리는 그 부작용을 정확히 겨냥한 것으로, 판단이 옳다.

### 5-1. 신규 `rearmLazyLoader()` (`:108-117`) — **R-1 재발 없음** ✅

**속성이 남아 있는 이미지만** 고른다. 우리 14장은 `:294` 에서 이미 속성이 지워졌으므로 **선택 대상 밖**이다.
