## 2. 이미지 순서 교정 (중요 — 다른 페이지와 다른 처리)

`assets/detail/magnesium/01~16.webp` 의 **파일명 순서는 공홈 게시 순서와 다르다.**
칼륨·비타민B는 원본 URL이 전부 `copy-<타임스탬프>-NN_...` 형식이라 문자열 정렬 = 게시 순서였지만,
마그네슘만 `00_brandimage.png`·`02_…`~`14_…` 와 `copy-…-00_공식판매처`·`copy-…-01_checklist` 가 섞여 있어 정렬이 뒤집혔다.

공홈 `ec-data-src` 실제 게시 순서로 다시 매핑해 배열을 구성했다:

```
15(공식판매처) → 01(무드 히어로) → 16(체크리스트) → 02(범인은 긴장) → 03 → 04 → 05 → 06 → 07
→ 08(Point1 원료) → 09(Point2 400mg) → 10(Point3 Kolmar BNH) → 11(Summary) → 12(Q&A) → 13(end) → 14(표시사항)
```

Playwright로 실제 렌더 순서를 눈으로 확인했다(pm_03 = 공식판매처 배너 → "하루의 마무리 힐링 루틴" 히어로).
**`assets/detail/README.md` 의 "파일명은 공홈 게시 순서 그대로"는 마그네슘에 한해 사실이 아니다** — 아래 확인 필요 항목에 남긴다.

## 4. 확인 필요 항목

1. **평점 4.8 · 리뷰 54건** — 공홈 JSON-LD 값이다. 다른 페이지에 박혀 있는 알파리뷰 위젯 집계(칼륨 4.9·26,961건)는 정적 HTML에 실리지 않아 curl로 읽히지 않는다. 대표님이 알파리뷰 관리자 실수치를 주시면 즉시 교체하겠다.
2. **5박스 할인 표기** — 공홈은 `[지금 3+2▼]` 라는 프로모션 표기를 쓰는데, 페이지는 옵션 카드에서 정가 대비 할인율을 자동 계산해 **38%** 로 표시한다(245,000 → 153,000). 공홈 문구 그대로 "3+2"로 보여야 한다면 알려주시면 바꾸겠다.
3. **`assets/detail/README.md` 정정 필요** — 위 2절대로 마그네슘 폴더의 파일명 순서 ≠ 공홈 게시 순서다. README에 예외를 명기하거나 파일을 게시 순서로 리네임해야 다음 사람이 같은 함정에 빠지지 않는다.
4. **aic 원료 표기** — 상세 08·11번에 "아메리칸 인터내셔널 케미컬(aic) 순도 97.4% 산화마그네슘"이 명시돼 있어 뱃지로 넣었다. 상단 뱃지에는 순도 수치까지는 넣지 않고 "미국 aic 산화마그네슘"으로만 축약했다.
5. **추가상품 향(香) 표기** — 비타민B "사과향", 칼륨 "라임향"은 비타민B 페이지에서 그대로 가져온 값이다. 칼륨 표시사항 원본은 아직 확보하지 않아 "라임향"의 1차 근거는 미확인 상태다(비타민B 보고서 3-2항과 같은 건).
