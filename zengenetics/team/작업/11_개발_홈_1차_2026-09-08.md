# 3. 코드 착수 중에 잡은 결함 2건 — **실렌더가 아니었으면 못 잡았다**

## 3-1. 조건 ④ 의 스크롤 복원이 **작동하지 않았다** (설계 결함)

설계 §6-5 는 *"붙는 순간 현재 `scrollY` 를 저장"* 이라고 썼다. **그대로 짰더니 복원값이 0 이었다.**

```
before: 1544  →  frozen: true  →  afterFixed: 0  →  restored: 0   ← 실패
```

**원인:** `body{position:fixed}` 가 적용되는 순간 문서 높이가 무너져 브라우저가 스크롤을 0 으로 되돌린다.
`MutationObserver` 콜백이 깨어난 시점에는 **이미 `pageYOffset` 이 0** 이다.
저장 시점이 늦다 — 설계 문장 자체가 틀렸다.

**수정:** 동결 시점에 읽지 않고, **평소 스크롤에서 `lastY` 를 상시 기록**해 그것을 복원값으로 쓴다.

```
before: 1629  →  frozen: true  →  afterFixed: 0  →  restored: 1629  ← 5뷰포트 전부
```

## 3-2. 하네스 자체 버그 — `offsetTop` 은 문서 좌표가 아니다

제품 블록 스크럽이 안 도는 것처럼 보였다(`idx [0,0,0]`). 코드가 아니라 **내 검사 스크립트**가 틀렸다 —
`.zg-track` 의 `offsetParent` 는 `.zg-pblock`(position:relative)이라 `offsetTop` 이 문서 좌표가 아니다.
`getBoundingClientRect().top + pageYOffset` 로 고치니 `idx [0,17,23]` 로 정상 동작했다.
**검사가 틀려서 코드를 의심한 사례다. 기록해 둔다.**

## 5-2. ★ 음성 대조군 — **`.zg-home{overflow-x:hidden}` 은 정말로 sticky 를 죽인다**

설계 §6-4 의 자기정정이 맞는지 실제로 재현했다.

```

주입 (.zg-home{overflow-x:hidden}): overflowX=hidden   overflowY=auto     stageTop=-1629
```

`overflow-y` 가 **`auto` 로 계산되어** `.zg-home` 이 스크롤 컨테이너가 되고, 히어로가 그냥 흘러가 버린다.

# 9. 개발이 가장 불안한 것

**1) 조건 ④ 의 3초 안전장치가 최선인지 모르겠다.**
`removeClass('eMobilePopup')` 리터럴이 두 번들에 **0건**이라 *"안 떨어질 수도 있다"* 를 전제로 짰다.
3초는 근거 있는 숫자가 아니라 **"멈춘 화면을 3초 이상 두지 않는다"** 는 판단이다.
실기에서 검색창을 3초 넘게 열어 두면 히어로가 그동안 진행률을 놓친다 — 닫으면 복원되지만 그 3초는 어긋난다.

**2) R17(모바일 무한 `setInterval`)은 여전히 못 고친다.**
삭제 금지 파일 안이고 지금 라이브에도 이미 있다. SwiftShader 렌더에서는 부드러웠지만
**실기기 체감은 대표님 폰이 최종 판정**이다.

**3) 픽스처는 라이브가 아니다.**
CSS 번들을 6번 자리에 끼워 넣고 `main_js.html` 원문까지 넣었지만,
스킨 자산 일부(폰트·아이콘)가 404 인 채로 쟀다. **미리보기 실기를 대체하지 못한다.**

**4) 하네스가 홈을 안 본다.** §7 이 반영되기 전까지 홈은 회귀 방어망 밖이다.
