# 대표님 아트디렉션 — 홈 개편 (2026-09-10 접수, 원문 보존)

> 이 문서는 **대표님이 직접 주신 지시 원문**이다. 요약·재해석하지 마라.
> 이후 모든 설계서·개발·QA 판정은 이 문서의 항목 번호를 근거로 인용한다.

## 1. 부족한 것은 '애니메이션 개수'가 아니라 세 가지 변화

이미 움직임은 있다(제품 회전, 배경 전환, 물속 확산, 숫자 변화). 그런데 **대부분 같은 거리에서 대상을 바라보는 움직임**이다.

| 현재 장면 | 부족한 변화 | 추가해야 할 것 |
|---|---|---|
| 배경 위에 스틱이 떠 있음 | 제품을 바라보는 거리가 거의 비슷함 | 전체 → 접사 → 극접사 |
| 포는 닫힌 모습으로 등장 | 제품의 상태가 바뀌지 않음 | 닫힘 → 개봉 → 분말 노출 |
| 물컵 안에서 색이 퍼짐 | 변화가 컵 안에 갇힘 | 컵 안의 변화가 화면 전체로 확장 |
| 배경과 제품이 교체됨 | 앞 장면과 다음 장면의 물리적 연결이 약함 | 같은 스틱·같은 분말이 다음 장면까지 이어짐 |
| 제품마다 설명 구조 반복 | 스크롤해도 다음 경험을 예상할 수 있음 | 제품별로 다른 장면과 행동 |

핵심은 **크기 변화 + 상태 변화 + 장면 연결**. 이 셋이 함께 있어야 스크롤이 페이지 이동이 아니라 **제품을 탐색하는 행동**이 된다.

중심 경험:
> 한 포를 발견한다 → 가까이 다가간다 → 연다 → 가루 속으로 들어간다 → 설계된 내용을 이해한다 → 내 하루에 가져온다.

## 2. 첫 화면: 명상 사진 대신 '하나의 거대한 스틱'

명상 사진은 웰니스라는 분야는 설명하지만 젠제네틱스라는 제품의 차이는 못 보여준다. **첫 화면의 가장 좋은 자리를 제품에 준다.**

- 배경은 밝은 회백색. 상단은 밝고 하단은 살짝 어두운, 깊이가 느껴지는 공간
- 스틱 한 포를 화면 중앙보다 **약간 오른쪽**
- 스틱 높이는 사용 가능한 화면 높이의 **약 75%**
- 수직으로 세우지 말고 **약 18° 기울여** 대각선으로 화면 사용
- 제품 아래에 바닥과의 거리가 느껴지는 부드러운 그림자
- 왼쪽 위에 짧은 카피. 설명문·성분 배지·가격·프로모션을 한꺼번에 넣지 않기
- 브랜드 로고와 메뉴는 작게

첫 카피 예: `하루의 균형을, / 한 포에.`

'꽉 찬 느낌'은 많은 요소가 아니라 **대각선으로 크게 놓인 스틱 + 가까운 그림자 + 표면의 빛**으로 만든다.

**첫 스크롤의 움직임**: 처음엔 제품 전체를 알아볼 수 있게 유지 → 스크롤하면 기울기가 **18° → 6°** 로 줄고 동시에 시점이 가까워진다.
**배경 전체가 똑같이 커지면 사진 확대처럼 보인다. 제품은 가까워지되 배경은 거의 움직이지 않게.**

첫 화면에서 뺄 것: 명상 사진(후반 루틴 장면으로 이동) · 장식용 선·마름모·원 · 제품 주변 배지 · 큰 고정 할인 바(메인 연출 뒤로).

**통과 기준: 화면을 정지해도 "명상 사이트"보다 "젠제네틱스 제품"이 먼저 보여야 한다.**

## 3. 두 번째 장면: 주인공은 스틱이 아니라 '절취선'

스틱 전체를 보여주려는 생각을 버린다.

- 제품 **상단 20~30%만** 화면에 남도록 접근. 몸통은 아래로 잘려도 된다
- **절취선은 화면 높이의 약 40% 지점**
- 확대된 포의 폭은 **모바일 화면 너비의 약 55~70%**
- **인쇄, 밀봉 자국, 포장재의 미세한 주름이 보여야 한다**

| 구간 | 움직임 |
|---|---|
| 접근 전반 | 스틱 상단이 화면 중앙으로 이동 |
| 접근 후반 | 제품이 커지며 몸통 하단이 화면 밖으로 |
| 잠깐 유지 | 절취선과 재질을 볼 수 있게 변화량을 줄임 |
| 개봉 시작 | 윗부분이 몸통과 다른 방향으로 움직이기 시작 |

**확대 중심 주의**: "3배 확대해"라고 하면 중앙만 확대돼 절취선이 화면 밖으로 나간다. 반드시 **"절취선의 화면상 위치를 유지하면서 제품을 확대"**로 지정.

카피: `뜯어서, / 3초면 끝.` — 단, 이 문장이 나올 때 **실제로 개봉 동작이 이어져야** 한다.

## 4. 세 번째 장면: 개봉은 '뚜껑이 떠오르는 효과'로 만들면 안 된다

윗부분을 직사각형으로 잘라 위로 올리면 포가 아니라 **뚜껑 달린 용기**처럼 보인다.

- 절취선 **한쪽에서** 열리기 시작
- 분리되는 상단 조각이 **반대쪽으로 살짝 휘며** 움직임
- 몸통은 거의 같은 위치 유지
- 열린 입구에서 **어두운 내부와 얇은 포장재 두께**가 보임
- 떨어진 상단 조각은 주인공이 되지 않게 화면 밖으로
- 이어서 스틱이 기울어지며 분말이 입구 쪽으로 이동

움직임 범위 제안: 상단 조각 = 옆으로 제품 폭의 약 0.5배 이동하며 기울어짐 / 몸통 = 개봉 순간 작은 반응만 / 개봉 후 = 입구가 아래를 향하도록 방향 전환.
**정확한 물리는 실제 포를 개봉한 참고 영상에 맞춘다. 위 수치보다 제품 구조가 우선.**

**소재가 부족하면 대안**: 개봉을 어설프게 가짜로 만들지 말고, **닫힌 포 접사 → 실제로 열린 입구 접사**로 짧게 전환하고 분말 흐름을 잇는 편이 낫다.

**통과 기준: 멈춰서 봐도 실제 제품을 여는 모습으로 이해돼야 한다.**

## 5. 네 번째 장면: '가루 제형'은 최소 세 번 다른 거리에서

**지금 홈에서 가장 크게 보강할 부분.** 한 번 떨어뜨리고 끝내면 "가루구나"까지만 안다.

**A. 제품과 가루가 함께 보이는 거리** — 화면 위쪽에 기울어진 열린 스틱, 입구에서 가루가 아래로. **가루의 출발점이 반드시 스틱 입구.** (지금 물컵 장면처럼 위에서 색만 들어오면 제품과 내용물의 연결이 약하다)

**B. 가루의 흐름을 가까이** — 스틱은 위로 빠지고 흐름이 중심에. 가는 선으로만 흐르지 않고 **아래로 갈수록 넓어짐**. 측면광이 입자 표면을 드러냄. 배경은 명도 차 확보.

**C. 가루 사이로 들어가는 거리** — 가까운 입자가 화면 가장자리를 크게 지나감. 중심 입자는 선명, 가장 가까운 일부는 흐려짐. 먼 입자는 작고 느리게.

| 레이어 | 보이는 모습 | 역할 |
|---|---|---|
| 전경 | 크고 일부 잘린 입자·덩어리 | 시점이 안으로 들어가는 느낌 |
| 중간 | 질감을 읽을 수 있는 분말 | 제형 전달 |
| 배경 | 작고 옅은 흐름 | 깊이 유지 |

**주의: 가루를 '반짝이는 별'로 바꾸지 말 것.** 제작 지시에 **"실제 분말 접사의 질감을 기준으로 하고, 균일한 원형 점이나 반짝이로 대체하지 말 것"** 을 넣는다.

## 6. 다섯 번째 장면: 절정은 '폭발'이 아니라 '넓게 펼쳐졌다가 정돈되는 순간'

주스 광고식 폭발보다 **분말의 넓은 흐름이 점차 고요해지는** 연출이 브랜드에 맞다.

진행: 가까운 분말이 시야를 지나 화면을 채움 → 수직 낙하가 넓은 곡선으로 → 화면 중앙에 빈 공간 → 주변 움직임이 작아짐 → 중앙에 성분 정보.

여기부터는 **추상적 브랜드 연출**로 다룬다. 실제 분말의 움직임이나 성분 작용을 설명하는 그림으로 오해하게 만들면 안 된다.

빛과 색: 흰 분말은 회백색·먹색 배경과 대비 / 제품별 포인트 색은 **빛의 가장자리나 배경 일부에 제한적으로** / 전체를 강한 빨강·보라로 채우지 말고 **스며드는 느낌** / 밝은 부분과 어두운 부분이 있어야 깊이가 생김.

카피는 한 번에 하나만: `한 포 안에, / 필요한 내용을 분명하게.`

## 7. 여섯 번째 장면: 성분표를 없애지 말고 '가까이 보여주는 정보'로

「한 포 안에 든 것」 표는 필요하다. 문제는 **긴 페이지에서 세 번 비슷한 형식으로 반복**되는 것.
메인에서는 핵심 한두 개를 크게, 자세한 표는 **열어보게**.

칼륨 구간 예: 중앙에 확인된 핵심 함량 → 바로 아래 **한 포 기준인지 하루 섭취량 기준인지 명확히** → 옆/아래에 다시 작아진 스틱 → 하단에 「원료·전체 구성 보기」 버튼.

**숫자는 0부터 올라가는 것보다 완성된 정확한 값을 안정적으로 보여준다.**
녹화에서 평점이 중간 숫자로 올라가는 순간이 보인다(2점대·3점대처럼 보임). **평점·함량처럼 정확성이 중요한 값은 숫자를 변화시키지 말고 나타나는 방식을 바꾼다**: 아래에서 16px 올라오며 등장 / 투명도만 변화 / 작은 글자는 약간 늦게 / 등장 후 고정.

## 8. 물컵 장면은 이렇게 개편하면 살릴 수 있다

**세 번 반복하는 주연출 → 한 번의 선택적 경험.**

작은 제목: `당신의 방식으로, 한 포.` 선택지는 실제 안내 가능한 섭취 방식에 맞춰 구성하고, 물에 타는 것을 고르면 기존 컵 연출.

| 단계 | 화면 |
|---|---|
| 1 | 컵 전체가 보임 |
| 2 | 열린 스틱이 들어오고 분말이 컵으로 |
| 3 | 컵이 커지며 수면이 화면 중앙에 |
| 4 | 컵 위아래가 잘리고 물속 확산이 화면 대부분을 |
| 5 | 확산된 색이 옅어지며 다음 화면 배경으로 |

**컵을 20% 키우는 게 아니라 전체 → 수면 → 물속으로 구도를 바꾸는 게 핵심.**
색과 퍼지는 모습은 실제 제품 기준. 예쁜 액체 장면과 실제로 물에 탔을 때의 모습은 구분한다.

## 9. 아침·저녁·밤은 사진 세 장 대신 '하나의 공간에서 빛이 변하는 장면'

같은 테이블, 같은 벽, 같은 카메라 구도.
아침 = 옆에서 길게 들어오는 밝은 빛 / 저녁 = 낮고 따뜻한 빛 / 밤 = 주변은 어둡고 제품을 비추는 제한된 빛.
시간이 변할 때 해당 제품이 앞으로 나온다.

| 항목 | 유지 | 변경 |
|---|---|---|
| 공간 | 같은 테이블·벽 | 빛의 방향과 색 |
| 제품 | 같은 크기 기준 | 해당 제품의 위치 |
| 글자 | 같은 위치와 서체 | 시간대별 짧은 문장 |
| 움직임 | 절제된 속도 | 제품이 앞으로 나오는 순서 |

**복용 시간 문구는 실제 제품 안내와 브랜드 확정 기준에 맞춘다.** 여기 제안은 시각적 표현이다.
명상 이미지는 이 구간 **뒤에** 짧게 배치 가능. 첫 장면의 주인공은 제품.

## 10. 구매 화면도 '제품이 보이게'

앞에서 크게 경험시켜 놓고 마지막이 작은 텍스트 목록이면 연결이 끊긴다.

- 앞 장면의 스틱이 작아지며 **제품 카드 위치에 도착**
- 세 제품이 나란히. 모바일은 하나를 중심으로 좌우 일부가 보이게 가능
- 제품마다 이름·핵심 차이·가격·선택 버튼이 **같은 위치**
- 데이팩은 별도의 명확한 선택지
- 전체 구성과 FAQ는 그 아래

**핵심: 제품 카드가 갑자기 나타나는 게 아니라, 방금 보던 제품이 구매 가능한 제품으로 정착한다.**

첫 구매 바 동작 분리: 첫 제품 연출 중 = 숨기거나 작게 접기 / 성분 정보 이후 = 구매 진입 버튼 표시 / 상품 선택 화면 = 해당 화면 버튼 중심.

## 11. 스크롤 안무 (모바일 메인 경험 첫 구현안)

'화면 높이' = 브라우저 상하단 UI 제외한 사용 가능한 높이.

| 장면 | 스크롤 진행 거리 | 시작 상태 | 종료 상태 |
|---|---|---|---|
| 제품 인식 | 화면 높이 **0.5배** | 큰 스틱 전체 | 제품 방향 정돈 |
| 절취선 접근 | **0.8배** | 전체 제품 | 상단 접사 |
| 개봉 | **0.6배** | 닫힌 포 | 열린 입구 |
| 분말 낙하 | **0.8배** | 제품과 분말 함께 | 분말 흐름 중심 |
| 분말 공간 진입 | **0.8배** | 흐름 전체 | 전경·중경·배경 분리 |
| 정돈과 정보 | **0.7배** | 넓은 움직임 | 정보가 읽히는 안정된 구도 |
| 다음 구간 연결 | **0.4배** | 성분 정보 | 루틴 또는 상품 화면 |

**총 약 화면 높이의 4.6배로 시작해서 조정.** 길수록 좋은 게 아니라 각 행동을 이해할 거리를 확보하는 목적.

동작 조건:
- 스크롤을 내리면 진행, 올리면 이전 상태로 되돌아간다
- 스크롤을 멈추면 핵심 동작도 멈추거나 짧게 따라잡고 정지
- 포를 여는 도중 다음 장면으로 갑자기 넘어가지 않는다
- 빠르게 스크롤해도 **빈 화면이나 소재 로딩 화면이 나오지 않는다**
- 큰 변화 뒤에는 정보가 읽히는 구간을 둔다
- 모바일에서 글자와 제품의 핵심 부분이 겹치지 않는다
- 가로 화면 레이아웃을 단순 축소하지 않고 모바일용 구도를 쓴다

**정확한 라이브러리 이름보다 이 동작 조건과 장면의 시작·끝 정의가 먼저.**

## 12. 필요한 소재 목록

| 필요한 소재 | 구체적인 내용 | 쓰이는 장면 |
|---|---|---|
| 스틱 전체 이미지 또는 모델 | 로고·인쇄·비율이 실제 제품과 일치 | 첫 화면·구매 연결 |
| **스틱 상단 접사** | 밀봉, 절취선, 포장재 질감이 보임 | 접근 |
| **개봉 시퀀스** | 닫힌 상태부터 열린 입구까지 | 개봉 |
| **분말 낙하 시퀀스** | 같은 입구에서 실제 가루가 나오는 구도 | 제형 소개 |
| **분말 접사** | 입자 크기·색·질감 참고 | 확대 장면 |
| 추상 분말 공간 | 실제 제형과 연결되되 과장된 공간 연출 | 몰입 장면 |
| 통일된 루틴 공간 | 같은 구도의 아침·저녁·밤 | 웰니스 |

**공통 기준 필수**: 첫 화면 스틱과 개봉 영상의 스틱이 다른 각도·빛·비율이면 전환에서 티가 난다.
각 소재를 독립 생성하기 전에 **제품 위치·카메라 각도·빛 방향·배경색·시작 프레임·끝 프레임**을 맞춘다.
**AI 를 쓰더라도 제품 인쇄와 로고는 실제 자료 기준.** 화려하지만 제품 자체가 달라지는 결과는 못 쓴다.

## 13. 작업 순서 (한 번에 요청하지 말 것)

「전체 사이트를 웅장하게 바꿔줘」로 요청하면 다시 배경·입자·회전을 여기저기 추가하게 된다.

**① 기존 도입부만 교체** — 대상은 지금의 명상 화면부터 3종 소개까지. 상품 정보·FAQ·푸터는 유지.
완성 목표는 **큰 스틱 → 절취선 접근 → 열린 입구**까지. 가루 세계는 아직 안 붙여도 된다.

**② 분말 경험 추가** — 열린 입구와 연결해 낙하 → 접사 → 공간 진입.
소재가 없으면 **임의의 반짝이로 채우지 말고, 필요한 소재와 임시 표시를 구분**하게 한다.

**③ 정보와 루틴 연결** — 분말 운동이 끝나는 구도에서 함량 정보로, 같은 제품이 루틴 화면으로.

**④ 반복 제거와 구매 정돈** — 세 제품의 동일한 긴 구조를 줄이고 제품 선택·상세 보기로 재구성.

**가장 먼저 완성해야 할 결과**:
> 첫 화면에서 스틱 전체를 보고, 조금 내리면 포의 질감을 보고, 더 내리면 포가 열리고, 다시 내리면 실제 가루를 가까이 본다. 이 과정에서 제품이 새 이미지로 계속 교체되는 느낌 없이 **하나의 대상으로 이어진다.**

이 한 구간이 나오면 지금 사이트의 가장 큰 약점인 **"제품은 떠 있고 배경만 바뀌는 느낌"**을 바꿀 수 있다.

> 풍부하게 만든다는 건 화면에 물체를 더 얹는 게 아니라, **같은 제품에서 볼 수 있는 거리·각도·상태를 늘리는 것**이다. 지금은 '전체 모습'과 '물에 퍼지는 모습'에 집중돼 있다. 그 사이에 **표면·절취선·개봉·입구·분말 흐름·분말 접사**를 채워 넣는 것이 이번 작업의 핵심이다.
