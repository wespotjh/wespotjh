## 1. 두 행 유형의 실제 DOM — 미리보기 번들에서 복원했다

미리보기 `optimizer.php` JS 번들(1,965,764 B)을 iPhone UA 로 받아 **행을 만드는 함수 원문**을 그대로 뽑았다.
행은 서버 HTML 에 없고 이 코드가 선택 시점에 만든다.

### 1-1. `tr.option_product` — `buildMobileSoldInCells()` (모바일 UA)

```html
<td>
  [hidden input …] <p class="product">…</p>
  <p>
    <input type="number" name="quantity_opt[]" class="quantity_opt eProductQuantityClass" value="1" …/>
    <a href="#none" class="up eProductQuantityUpClass" …><img … class="option_box_up" alt="up"/></a> &nbsp;
    <a href="#none" class="down eProductQuantityDownClass" …><img … class="option_box_down" alt="down"/></a>
  </p>
</td>
<td class="right"><strong class="price">…<span class="ec-front-product-item-price">68,000원</span></strong>[mileage]</td>
<td class="center"><a href="#none" class="delete">…</a></td>
```

DOM 순서: **input → a.up → a.down**. `.up/.down` 이 **`<a>` 에** 붙어 있다.

### 1-2. `tr.add_product` — 추가구성상품 행 빌더 (모바일 UA, `EC_MOBILE_DEVICE === true` 분기)

```html
<p>
  <input type="number" name="quantity_opt[]" class="quantity_opt eAddProductQuantityClass" value="1" …/>
  <a href="#none" class="eAddProductQuantityUpClass" …><img … class="up …_up" alt="up"/></a> &nbsp;
  <a href="#none" class="eAddProductQuantityDownClass" …><img … class="down …_down" alt="down"/></a>
</p></td>
<td class="right"><strong class="price">…</strong></td>
<td class="center"><a href="#none" class="delete">…</a></td>
```

DOM 순서는 같은데 **`.up/.down` 이 `<a>` 가 아니라 `<img>` 에** 붙어 있다. `<a>` 에는 동작 클래스
`eAddProductQuantityUpClass / DownClass` 만 있다. **이것이 F-2 의 전부다.**

(데스크톱 UA 는 두 행 모두 `<span class="quantity">` 안에 `a.up eAddProductQuantityUpClass` 로 `.up/.down` 이 `<a>` 에 붙는다 — 그래서 데스크톱 블록은 안 걸렸다.)

### 1-3. 가격 칸을 놓는 스킨 규칙 (CSS 번들 원문)

```css
#totalProducts:not(.is-pc) table tbody tr { position: relative; … }
#totalProducts > table tbody tr:not(#totalProductsOption) { display:block; padding:20px; … }      /* (2,0,3) — 이 padding 이 이긴다 */
#totalProducts:not(.is-pc) > table > tbody > tr > td:nth-child(2) {                                /* = td.right (가격) */
  width:80px; text-align:right; position:absolute; bottom:16px; right:16px; line-height:30px; }
#totalProducts:not(.is-pc) > table > tbody > tr > td:first-child { display:flex; flex-wrap:wrap; align-items:center; width:100%; }
#totalProducts table p:not(.product) { position:relative; display:inline-block; width:103px; … }   /* 스킨 스테퍼 */
```

가격은 **행 오른쪽 아래에 절대배치**(80px 상자)다. 스테퍼가 그 자리까지 넓어지면 가격이 그 위에 그려진다.
