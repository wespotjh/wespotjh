## 0. 왜 이 문서가 코드보다 먼저인가

아트디렉션 §12 마지막 문단:
> 첫 화면 스틱과 개봉 영상의 스틱이 **다른 각도·빛·비율이면 전환 순간에 티가 난다.**
> 각 소재를 독립적으로 생성하기 전에 제품 위치, 카메라 각도, 빛 방향, 배경색,
> 시작 프레임과 끝 프레임을 맞춰야 한다.

**소재를 하나씩 예쁘게 뽑으면 반드시 실패한다.** 아래 고정값을 모든 생성에 그대로 넣는다.

## 3. 장면별 소재 (작업 ① 범위 = 큰 스틱 → 절취선 접근 → 열린 입구)

### S1. 제품 인식 — 큰 스틱 전체
| 항목 | 값 |
|---|---|
| 구도 | 스틱 1포, 화면 중앙보다 **약간 오른쪽** |
| 크기 | 스틱 높이 = 화면 높이의 **75%** |
| 기울기 | **18°** (우측 상단 방향) |
| 상태 | 닫힌 포. 상·하 밀봉 모두 보임 |
| 여백 | 왼쪽 위에 카피가 들어갈 빈 공간 확보 (제품과 겹치지 않게) |
| 필요 산출 | 정지 이미지 1장 (고해상도) |

### S2. 절취선 접근 — 상단 접사
| 항목 | 값 |
|---|---|
| 구도 | 제품 **상단 20~30%만** 화면에 남음. 몸통은 아래로 잘림 |
| 절취선 위치 | **화면 높이의 40% 지점** |
| 포 폭 | 화면 너비의 **55~70%** |
| 기울기 | **6°** (S1 의 18° 에서 줄어든 끝값) |
| 반드시 보여야 | 톱니 압착 자국 · 인쇄 · 포장재의 미세한 세로 주름 |
| 필요 산출 | 정지 이미지 1장 + S1→S2 중간 단계 **6~10 프레임** |

> **확대 중심 주의(§3)**: 「3배 확대」로 지시하면 중앙만 커져 절취선이 화면 밖으로 나간다.
> 반드시 **「절취선의 화면상 위치를 유지하면서 제품을 확대」** 로 지시한다.

### S3. 개봉 — 닫힘 → 열린 입구
| 항목 | 값 |
|---|---|
| 시작 | S2 의 끝 프레임과 **완전히 동일한 구도** |
| 열림 방식 | 절취선 **한쪽에서** 시작. 상단 조각이 **반대쪽으로 휘며** 이동 |
| 상단 조각 | 옆으로 제품 폭의 **약 0.5배** 이동하며 기울어짐. 이후 화면 밖으로 |
| 몸통 | 개봉 순간 **작은 반응만**. 크게 흔들지 말 것 |
| 열린 입구 | **어두운 내부**와 **얇은 포장재 두께**가 보여야 함 |
| 절대 금지 | 상단을 직사각형으로 잘라 위로 띄우는 것 (= 뚜껑 달린 용기처럼 보임) |
| 필요 산출 | **10~16 프레임** 시퀀스 |

**소재가 어설프면 대안(§4)**: 가짜 개봉을 만들지 말고 **닫힌 포 접사 → 실제로 열린 입구 접사** 두 장으로 짧게 전환한다.

## 4. 검수 통과 기준 (QA 가 판정할 항목)

| # | 기준 | 근거 |
|---|---|---|
| 1 | 정지 화면에서 「명상 사이트」가 아니라 **「젠제네틱스 제품」**이 먼저 보인다 | §2 |
| 2 | S2 에서 **톱니 압착 자국·인쇄·주름**이 실제로 읽힌다 | §3 |
| 3 | S3 를 멈춰서 봐도 **실제 제품을 여는 모습**으로 이해된다 | §4 |
| 4 | S1·S2·S3 의 스틱이 **같은 제품**으로 보인다 (각도·빛·비율·인쇄 일치) | §12 |
| 5 | 인쇄·로고·문구가 실물 레퍼런스와 **한 글자도 다르지 않다** | 영구 규칙 |
| 6 | 반짝이·보케·먼지 입자가 **0개** | §5 |

**5번은 눈으로 대조한다.** 생성물의 라벨 영역을 잘라 `pot-stick-real.png` 와 나란히 놓고 확인한다.
글자가 뭉개지거나 다른 글자로 바뀐 컷은 **크기와 무관하게 반려**한다.
