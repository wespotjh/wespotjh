2. `ec-data-src` 속성을 전수 추출 → **190장** (전부 `/web/upload/NNEditor/YYYYMMDD/mobile/*.png`).

그러나 미달 폭이 **1~5px** 이고, 그때 발생하는 확대는 **최대 +0.79%(640/635)** 다.

| 폭 | 확대율 | 재현된 실패 모드와의 거리 |
|:--:|:--:|---|

**칼륨이 통과한 기준을 다른 상품이 못 넘길 이유가 없다.**

## 상수 없는 대안(`min-width:0; min-height:60vw`) 판정 — **채택하지 않는다**

신아린이 검증해 둔 대안은 **그 상품들에서도 성립한다**(확대가 원천 불가능하므로 폭이 얼마든 성립).
그러나 **채택 근거가 없다**:

| 항목 | 현재안 `min-width: min(100%, 640px)` | 대안 `min-width:0; min-height:60vw` |
|---|---|---|
| 최대 확대 | **+0.79%** (실측 190장 기준 상한) | 0% |
| 스크롤 전 이미지 요청 | **2~3장** (신아린 4차 실측) | **3~6장** (신아린 4차 실측) |
| 자리 예약 정확도 | `aspect-ratio: auto 640/948` 이 정확히 잡음 | 높이 floor 만 잡음 |
| md5 동결 | 유지 | **깨진다.** `detail.css` 재붙여넣기(45,551 B) + 4개 게이트 재판정 |

**+0.79% 를 없애려고 45,551 B 재붙여넣기와 게이트 4개 재판정을 사는 것은 남는 장사가 아니다.**
**단, 다음 판(`ZG_VER 2.003`)에 대안을 넣을 것을 권고한다** — 그때는 어차피 재붙여넣기가 발생하고,
**상수 자체가 사라지면 앞으로 등록되는 이미지의 폭을 영원히 신경 쓰지 않아도 된다.**

## 2-2. `p.product span` (배시우 N-7) — **13종 전수 「발생 불가」. 실측 0건**

발생 조건은 *"옵션이 없고 추가옵션(add_option)만 있는 상품"* 이다. 두 갈래로 확인했다.

**(가) 행 템플릿이 13종 전부 바이트 동일하다**
`#totalProductsOption` 뒤의 주석 템플릿을 13종에서 추출해 대조했다 — **전부 1,304자 동일**:
```
<!-- tr> <td> <p class="product"> $상품명<br /> <span>$옵션</span> </p> </td> …
```
`<span>` 이 템플릿에 항상 있다.

**(나) 추가옵션이 등록된 상품이 0종이다**
`<caption>옵션 정보</caption>` 테이블의 `<tbody>` 가 **13종 전부 비어 있다**(`<tbody> </tbody>`).
추가옵션 행이 렌더될 자리가 비어 있다 = **추가옵션 0개**.

→ **N-7 은 현재 라이브 13종 어디에서도 발생할 수 없다.** 배시우가 표본 9종에서 미발생이라 한 것이
13종으로 넓혀도 유지된다.

**그러나 B-1 을 장부에서 지우지는 마라.** `zg-ga4.js:178` 의
```js
var sp = r.querySelector('p.product span');
…
if (v) out.push({ variant: v, qty: q });     // ← span 없으면 행을 통째로 버린다
```

  장부 **A-6 에 「30초 확인」으로 이미 올라가 있다**. **추가 비용 0.**
- 62·60 과 완전 동형(옵션 0 · 추가상품 0 · `tbody class=""` · `visibleRows()=1`).
  61 이 통과하면 62·60 은 동형 통과다. (**60 은 회원전용이라 로그인 후 1회만 더 본다.**)

## 5-3. ★ 여기에 **1건을 반드시 더한다 — 93 멤버십 혜택 (1분)**

**이번 조사에서 새로 드러난 유일한 미검증 실패 모드다.** 34·91·93 은 **가격이 없는 상품**이고,
`detail-ui.js:678~681` 은 다음과 같다:
```js
if (num > 0) { barV.textContent = t; … }
else { barV.textContent = '구성을 선택해 주세요'; … }
```
`totalNum()` 이 0 이면 하단바가 **「구성을 선택해 주세요」** 라고 말한다.
그런데 34·91·93 은 **옵션이 없어 고객이 고를 것이 없다.** 게다가 `visibleRows()=1` 이라
구성카드 영역의 안내문(`.zg-picked-head__empty`)은 뜨지 않는다 — **하단바만 혼자 막다른 말을 한다.**

**93 을 고르는 이유:** 홈과 카테고리에서 링크되는 유일한 이벤트 페이지다(34·91 은 URL 직접 진입).
