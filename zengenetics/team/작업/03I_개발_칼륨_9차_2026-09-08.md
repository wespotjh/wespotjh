## 2. 신아린 P3 — `detail.css` 주석 "32px" → "30px" (주석 2줄 외 변경 0 증명)

번들 원문에서 `#totalPrice` padding 규칙의 미디어 문맥을 확인했다:

| 규칙 | 미디어 | 390px 에 적용 |
|---|---|:--:|
| `#totalPrice{padding:20px 0 30px}` | `@media all and (max-width:1024px)` | **✅ 이것** |
| `#totalPrice{padding:22px 0 32px}` | `@media all and (min-width:769px)` | ✗ (769~1024 에서는 뒤 선언이 이김 — 태블릿 폭) |

8차 보고 §4-2 의 "32px" 은 미디어 문맥을 안 보고 뒤 규칙을 읽은 내 착오다. **모바일 실측은 30px.** 신아린이 맞다.
37px 결론은 불변 — 30 + 바운스 5 + 여유 2 = 37. (하네스 C7 말풍선 간격 +5px 실측도 그대로.)

```diff
--- 8차 전달본 2_ds-css-detail.css.txt (90120f8c…)
+++ cafe24-skin/ds/css/detail.css (9차)
@@ -927 +927 @@
-     라이브는 `#totalPrice { padding: 22px 0 32px }` 의 아래 32px 이 그 자리를 비워 두었는데,
+     라이브는 `#totalPrice { padding: 20px 0 30px }`(≤1024px 미디어) 의 아래 30px 이 그 자리를 비워 두었는데,
@@ -929 +929 @@
-     라이브가 비워 두던 32px + 말풍선 바운스 진폭(`bubbleBounce` translateY -5px) 만큼 되돌린다
+     라이브가 비워 두던 30px + 말풍선 바운스 진폭(`bubbleBounce` translateY -5px) + 여유 2px 만큼 되돌린다
```

`diff` 출력이 위 2줄(927·929, 같은 주석 블록)뿐이다. 선언(`margin-top: 37px`)은 그대로. **8차 PASS 를 무효화하는 변경 0** — 렌더 결과 동일(C7 224/224 재확인, §5).

## 6. 이번 판에서 내가 틀렸던 것 (자진 기록)

1. **"저장소에 키를 안 넣는다"** 를 REST 키와 JS 키를 구분하지 않고 적용했다. 그 자리표시가 전달본 → 미리보기로 흘러 실제 회귀(공유 불능)가 됐다. T-1 대로 정정.
