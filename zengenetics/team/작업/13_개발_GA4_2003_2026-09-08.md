## 4-1. ★ 홈 C-1 스텁이 **iPad 세로(768px)에서 뚫린다** — 하네스 H 가 잡았다 (홈 3차 대상)

전체 실행에서 `H2.vp768.err.pause`(그리고 간헐적으로 `vp360`)이 다시 빨갛다. 홈 2차 제출 시점(07:04)에는 5/5 통과했고, 단독 재실행에서는 다시 통과한다 — **경쟁 조건**이다. 스택을 읽었다:

```
TypeError … (reading 'pause')  at MainBannerSlideMobile  ← jQuery ready 콜백(mightThrow) 경유
```

`main_js.html` 원문(픽스처 :2776·:2786): `MainBannerSlideMobile()` 은 **두 번** 불린다 — ready 콜백에서 1회, **`$(window).on('resize', …)` 에서 또 1회**. 그리고 함수 안에:
```js
if (winWidth <= 768 && runMainBannerSlideMobile == undefined) { … new Swiper … .autoplay.pause(); }
else if (winWidth >= 768 && runMainBannerSlideMobile != undefined) { runMainBannerSlideMobile.destroy(); runMainBannerSlideMobile = undefined; }
```
**폭이 정확히 768 이면 두 조건이 다 참이다.** 1회차: 스텁이 있으니 첫 분기 건너뜀 → 둘째 분기에서 **스텁을 `undefined` 로 되돌린다** → 2회차(resize): `== undefined` 가 참 → `new Swiper`(배너 없음 → undefined) → **던진다.** iPad 세로가 정확히 768px 이고 주소창 변화가 `resize` 를 낸다. 360 에서 난 것은 모바일 에뮬레이션 초기 레이아웃 폭이 잠깐 ≥768 이었던 것으로 본다(같은 기전).

**고치는 법(홈 3차, `index.html` 스텁 3줄 → 접근자):**
```js
(function(){ var s1={autoplay:{pause:function(){}},destroy:function(){}}, s2={autoplay:{pause:function(){}},destroy:function(){}};
  Object.defineProperty(window,'runMainBannerSlidePC',{get:function(){return s1},set:function(){},configurable:true});
  Object.defineProperty(window,'runMainBannerSlideMobile',{get:function(){return s2},set:function(){},configurable:true}); })();
```
`= undefined` 대입이 setter 에 먹혀 **가드가 영원히 닫힌다.** `var` 재선언은 기존 전역 접근자를 건드리지 않는다. 여전히 빈 객체 + no-op 2개 — Swiper 흉내 아님.
**지금은 못 고친다** — `index.html` 동결. **H 검사는 약화하지 않았다.** 3차 전까지 768 에서 간헐 FAIL 이 나는 것이 맞는 신호다.
