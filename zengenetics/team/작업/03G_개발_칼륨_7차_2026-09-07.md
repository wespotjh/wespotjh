## 1. F-1 (P0) — `parseOptionText()` 재작성

### 1-1. 조사자 지적이 맞다

관리자 옵션명 작명 규칙이 **두 가지**인데 예전 코드는 한 가지만 알고 있었다.

| 형 | 예 | 상품 |
|---|---|---|
| A | `[지금 24%▼] 젠제네틱스 붓기파우더 2 box (무료배송) (+33,100원)` | 11 · 13 · 16 · 71 |
| B | `🔥BEST🔥[4+2] (35%할인 \| 6주 \| 무료배송) (+76,000원)` | 63 · 64 · 98 |

예전 코드는 소괄호를 `(+N원)` 과 `(무료배송)` **두 형태만** 지웠다.
`(35%할인 | 6주 | 무료배송)` 은 어느 쪽에도 안 걸려 제목에 통째로 남았고,
B 형 BEST 옵션은 **원문에 상품명 부분이 아예 없어** 대괄호·이모지를 지우면 남는 것이 괄호 문구뿐이었다.

### 1-2. 고친 방식 — 지우지 않고 **옮긴다**

조사자 권고는 `.replace(/\d+%\s*할인\s*\|?/g,'')` 1줄이었지만, 그 방식은 `6주`·`60일` 같은
**남은 정보를 제목에 계속 남긴다**. 그래서 규칙을 뒤집었다.

- 소괄호는 **전부** 걷어낸다 (형태를 열거하지 않는다 — 새 작명 규칙이 와도 안 깨진다)
- 걷어낸 내용은 버리지 않고 `|` 로 쪼개 **칩으로 되돌린다** (정보 손실 0)
- 제목이 비면 **대괄호 → 메타 → 원문** 순으로 폴백한다 (어떤 작명에서도 제목이 비지 않는다)
- 숫자·문구를 **새로 만들지 않는다.** 원문 조각을 옮겨 붙일 뿐이다 (계산 금지 규칙 유지)

```js
    var nm = s
      .replace(/\(\s*\+\s*[\d,]+\s*원\s*\)/g, ' ')      /* 추가금은 따로 칩으로 나간다 */
      .replace(/\(([^)]*)\)/g, function (_m, inner) {   /* 나머지 소괄호 = 메타 정보 */
        meta.push(inner); return ' ';
      })
      .replace(/\[[^\]]*\]/g, ' ').replace(/🔥/g, ' ').replace(/BEST/gi, ' ')
      .replace(/\s+/g, ' ').trim();
    ...
    if (!nm) {                       /* B 형 BEST 옵션: 제목이 비는 경우 */
      if (bracket) { nm = bracket; usedBracketAsName = true; }
      else if (parts.length) nm = parts.join(' · ');
      else nm = s;
    }
```

반환값이 `tag`(문자열 1개) → `tags`/`notes`(배열 2개)로 바뀌어 카드 렌더 3줄도 같이 고쳤다.
**CSS 는 안 바꿨다** — `tags` 는 기존 `zg-opt__tag`, `notes` 는 기존 `zg-opt__add` 를 재사용한다.

## 5. N-7 기록 (장부 B-1 · 고치지 않음)

`ds/js/zg-ga4.js:178` `selectedOptionRows()` 는 이렇게 시작한다.

```js
      var sp = r.querySelector('p.product span');
```

`<span>` 이 없으면 `sp` 가 `null` → `cleanVariant('')` 가 빈 값 → **그 행이 통째로 버려진다**
(`item_variant` 결측 + 수량 누락). `detail-ui.js:160` 은 같은 상황에 `p.product` 전문으로 폴백하고
`tr[data-zg-nospan="1"]` 후크까지 남겨 두는데, **계측 쪽에는 그 폴백이 없다.**

**13종으로는 재현·반증 둘 다 불가하다.** `tr.option_product` 는 서버 HTML 에 존재하지 않고
스킨 JS 가 선택 시점에 만든다 — 13종 전부 서버 응답의 `#totalProducts p.product` 가 **0개**다.
따라서 *"어떤 상품이 `<span>` 없는 행을 만드는가"* 는 **실환경에서 실제로 담아 봐야** 확인된다.

⇒ 장부 B-1 유지. 다음 `ZG_VER` 인상 때 `zg-ga4.js` 를 어차피 재붙여넣기하므로 그때 1줄로 닫는다.
