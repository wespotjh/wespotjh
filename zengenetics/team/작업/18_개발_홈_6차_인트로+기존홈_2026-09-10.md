홈 모양이 바뀌었으므로 H 스위트를 같이 고쳤다. **기준을 느슨하게 한 게 아니라 대상을 옮겼다.**

| 예전 검사 | 지금 |
|---|---|
| 픽스처가 `@import` 를 전부 지우고 인트로만 렌더 | **라이브 홈 `main#contents` 원문을 우리 import 자리에 그대로 끼운다** — 기존 홈이 실제로 같이 렌더된다 |
| `@import` 정확히 2개 | 6개 + 끈 것 8개, **복구본과 목록 일치**를 새로 못 박음 |
| 스텁 3개 있어야 함 | **0개여야 함** (있으면 진짜 슬라이더를 막는다) |
| 랜드마크 = 가루 블록 3·프레임 72·썸네일 3 | 인트로 랜드마크 + **기존 홈 4구간 생존** + **인트로가 위인지 문서 좌표 대조** |

| H3 `body` 클래스 빈 문자열 | `body` 에 **zg- 접두 클래스가 없을 것** (스킨이 붙이는 `white` 는 기존 홈의 것) |

## 6. QA 에 특히 봐 달라는 것

1. **스텁 제거가 맞는 판단인가** — `main_js.html` 이 폭 전환 시 `destroy()` 후 변수를 `undefined` 로 되돌리는 경로가 있었다. 스텁 없이 회전 3종(`H8`) 은 통과했지만 실기 확인이 필요한지.
2. **히어로 구간 p95 63.8ms(6배 스로틀)** 를 판정 기준으로 세울 것인가, 관측으로 둘 것인가.
3. **고지 문구 위치** — 인트로가 연출 영상이라 문구가 필요한데 페이지 맨 아래로 내렸다. 인트로 직후가 맞는지.
4. **`#zgHomeJump` 앵커** — `aria-hidden="true"` 빈 div 다. 접근성·SEO 상 문제 없는지.
5. 배포 순서와 되돌리기 — index.html 한 파일 교체이고, 되돌림은 `전달/2026-09-09_홈복구/1_index.html.txt` 로 복귀.
