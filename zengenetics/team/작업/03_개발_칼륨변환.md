### 3-3. 4가지 조합 전부 검증 (플래그를 남겨 두므로 계속 유지해야 한다)

| 조합 | 동작 | 시뮬레이션 |
|---|---|---|
| `multi` / `false` (**확정값 · 기본값**) | 지금 라이브와 동일 = **회귀 0**. 카드 재탭 시 토스트, 2개 이상 담기면 안내문 | PASS |
| `multi` / `true` | 로드 후 BEST(2box) 카드 1회 자동 담기. 총액 0→68,000 | PASS |
| `single` / `false` | 다른 카드 탭 시 **카페24 자신의 `.delete` 컨트롤**을 눌러 이전 행 제거 → 항상 1행 | PASS |
| `single` / `true` | 진입 시 2box 자동, 이후 택1 유지 | PASS |

**single 경로의 안전장치 3중:**
1. 우리가 DOM 을 직접 지우지 않는다 — 카페24가 만든 삭제 컨트롤(`a.delete` / `.option_box_del` / `a[class*="delete"]`)을 **클릭**한다.
2. `change` 직후가 아니라 **`#totalProducts` 의 MutationObserver 가 새 행을 확인한 뒤** 정리한다(총액이 0으로 튀는 구간 없음).
3. 컨트롤을 못 찾으면 `modeEffective='multi'` 로 폴백하고 안내문을 띄운다. **행을 잃지 않는다.**
4. 2.5초 안에 새 행이 안 생기면 대기를 스스로 해제한다(무한 대기 없음).

## 5. 구현 메모 (QA·팀장이 읽어야 할 판단 5가지)

1. **총액은 한 곳에서만 읽는다.** `#totalPrice .total strong, #totalPrice .total em` → `(N개)` 꼬리 제거. `ds/js/ga4.js screenTotal()` 과 같은 규칙을 **복붙이 아니라 자체 함수**로 다시 썼다(파일 간 결합 회피). 우리 JS 안에 산술 연산은 없다.
2. **`#totalProducts` 안에 래퍼를 넣지 않았다.** 스킨 최고 구체도 셀렉터가 7단 자손 체인이라 한 칸만 끼워도 스타일이 통째로 증발한다. 선택목록 헤더는 `#totalProducts` **바깥 형제**다.
3. **`#totalProducts` 이동은 주석 노드 앵커로 되돌린다.** 원위치에 `<!--zg-totalproducts-home-->` 를 심어 두고 ≥768px 이면 그 앞으로 복귀시킨다. 리사이즈 왕복 검증 통과. 문제가 나오면 `ZG_MOVE_TOTALPRODUCTS = false` 한 줄.
4. **`.additional-inner` 의 자식 구조를 건드리지 않았다.** 칩·각주는 전부 `#prdDetail` **내부**다(`scrollTab()` 이 형제 인덱스를 쓴다).
5. **스크립트 2중 삽입 방어.** 카페24 편집기에서 실수로 두 번 붙여넣어도 카드가 두 벌 그려지지 않도록 `window.__ZG_DETAIL_UI__` 가드를 넣었다(시뮬레이션 중 실제로 8장이 그려지는 것을 잡아냈다).

## 7. 팀장(나윤설)에게 올리는 확인 항목

1. **결정 4건 반영 완료 — 되돌릴 작업 0건.** 브리프 「✅ 대표님 결정 확정」 표대로 `multi` / `autoselect false` / 추가상품 3종 / 아코디언 미제작. 플래그 2개는 지시대로 **남겨 두었고**, 8종 전개 후 A/B 때 한 줄로 뒤집을 수 있다(4조합 전부 검증 완료).
2. **K-12 z-index 결정** — 기획(시트가 바를 덮음) vs 디자인(바가 위, 시트 열리면 버튼행만 접힘) 이 달라 **디자인 안을 택했다.** 시트 안에서도 결제 금액이 계속 보이는 쪽이다. 뒤집으려면 `--zg-z-bar: 9` 한 줄.
3. **`#totalProducts` 모바일 이동** — 기획 §11-4 의 "되돌릴 수 있게" 요구를 안전핀 1줄로 만들었다. QA 에서 무료배송바 갱신 실패·PC 2단 붕괴가 나오면 `false`.
4. **별 색·`th` 글자색·도트 위치·수량칸 폭 4가지는 의도적으로 양보했다.** 이기려면 새 `!important` 부채를 져야 한다. 디자인 문서의 판단을 그대로 따랐다.
5. **`.txt` 전체 코드 복붙본** — 대표님 영구 지시대로 4개 파일 전문을 `.txt` 로 뽑는 작업은 팀장 컨펌 후 진행한다(부분 diff 금지).
