# 젠제네틱스 사이트 구조 — AS-IS 파악 + TO-BE 초안

**작성:** 2026-09-02 · 브랜드 문서(`.agents/product-marketing.md`) v3 기준
**용도:** 리뉴얼 와이어프레임 작업 시 "꼭 필요한데 빠진 페이지"가 없도록 하는 체크리스트.

## AS-IS: 검색으로 확인된 현재 구조 (카페24)

- `/` — 홈 (타이틀: "젠제네틱스｜건강한 파우더리 데일리 루틴")
- `/product/detail.html?product_no=11` — 포타슘 칼륨 (20ea) 34,900원
- `/product/detail.html?product_no=16` — 마그네슘 (20ea) "숙면을 위한 마그네슘 루틴"
- `/product/detail.html?product_no=13` — 비타민B컴플렉스 (20ea) 49,000원
- `/product/detail.html?product_no=62` — 비타민B컴플렉스 데이팩 (6ea)
- `/product/.../71/category/1/...` — 생애 첫 구매 이벤트 (SEO 타이틀: "붓기제거 추천｜붓기파우더 젠제네틱스 공식몰")
- 이벤트: "젠제네틱스 x 뱃프콘 시즌3" 바디프로필 콘테스트 (미용·피트니스 프레임 → 리뉴얼 방향과 충돌 검토)
- 다국어 흔적: 한국어/중국어

### ⏳ 새 세션(네트워크 전체)에서 확정할 것
- [ ] 전체 메뉴(GNB) 구성과 카테고리 트리
- [ ] 브랜드 스토리/회사소개 페이지 존재 여부
- [ ] 후기(리뷰) 페이지 구성 방식
- [ ] 이벤트/공지 게시판 목록
- [ ] 설인아 모델 이미지가 쓰인 위치 전수 조사 (교체 대상 목록)
- [ ] 푸터 구성 (사업자정보, 이용약관, 개인정보처리방침)
- [ ] 현재 스킨의 모바일 대응 상태

## TO-BE: 리뉴얼 사이트맵 초안

필수(카페24 기본 제공 포함)와 신규 제작을 구분. ★ = 이번 리뉴얼의 핵심 제작 대상.

### 메인
- ★ **홈** — 시그니처 모션(스틱포 개봉→가루 쏟아짐→성분별 역할 스토리텔링), 네이비+화이트+우드톤
- ★ **브랜드 스토리** — 웰니스 리포지셔닝의 얼굴. 왜 미네랄인가, 왜 파우더인가 (노셀럽, 근거 중심)

### 제품
- ★ **제품 목록** — 고민 기준 진입(붓기/수면·리커버리/활력)
- ★ **제품 상세 ×3 (+데이팩)** — Seed식 스크롤 근거 증명 구성, 성분·함량 투명 공개, 복용 시나리오
- **루틴 가이드** — 언제 뭘 먹는지 (짠 날 저녁엔 칼륨, 자기 전 마그네슘…) — 구매 전환 보조

### 신뢰
- **후기** — 카페24 리뷰 연동, 고객 언어 그대로 노출
- **FAQ / 고객센터** — 배송·교환·복용 질문

### 운영
- **이벤트/공지** — 첫 구매 혜택 등 (뱃프콘류 미용 프레임 이벤트는 방향 재검토)
- 카페24 기본: 로그인/회원가입, 장바구니, 주문/결제, 마이페이지 — 스킨 톤만 맞추고 구조는 유지
- 법정 필수(푸터): 사업자정보, 이용약관, 개인정보처리방침

### 보류/확인
- [ ] 중국어 등 다국어 유지 여부
- [ ] 정기구독 도입 여부 (도입 시 구독 안내 페이지 추가)

## 작업 순서 제안 (4단계 구현 시)
1. 홈 (시그니처 모션 포함 — 방향 확정용)
2. 제품 상세 1종(칼륨) → 확정된 패턴으로 나머지 2종 복제
3. 브랜드 스토리
4. 목록/후기/FAQ/이벤트 등 지원 페이지
5. 카페24 스킨 적용 + 모바일 검수
