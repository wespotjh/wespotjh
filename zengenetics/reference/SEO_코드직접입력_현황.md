대표님 스크린샷 + 라이브 소스 대조로 확인.
위치: **카페24 관리자 › 쇼핑몰 설정 › 검색엔진 최적화(SEO) › 고급설정 › 코드 직접입력**
(앱이 아니다. 설치 앱 25개 중 어느 것도 아니었다.)

| 탭 | 영역 | 내용 |
|---|---|---|
| PC 쇼핑몰 | Head | `G-84HNK1MRBG` gtag 스니펫 + GTM `GTM-5W5PV3CD` |
| PC 쇼핑몰 | Body | GTM noscript + JSON-LD `Organization` |
| 모바일 쇼핑몰 | Head | `<title>붓기제거 추천 ｜ 붓기파우더 젠제네틱스 공식몰</title>` + meta description/keywords |
| 모바일 쇼핑몰 | Body | JSON-LD `Organization` |

## 이것 때문에 생긴 문제 2개 (라이브 소스로 확인)

### ① `<title>` 이 페이지마다 두 개다 — 그리고 **먼저 나오는 쪽이 이긴다**

```
상품페이지(칼륨)
  81,056 바이트  <title>젠제네틱스｜건강한 파우더리 데일리 루틴</title>   ← 코드 직접입력이 넣은 것
 120,983 바이트  <title>젠제네틱스 포타슘 칼륨 (20ea) | 붓기 제거 · … | Zengenetics</title>

홈
  77,639 바이트  <title>젠제네틱스｜건강한 파우더리 데일리 루틴</title>
 116,519 바이트  <title>젠제네틱스 공식몰</title>
```

브라우저와 검색엔진은 **첫 번째 `<title>`** 을 쓴다.
→ **모든 페이지가 구글에 같은 제목으로 보인다.** SEO 설정에 정성껏 넣은
`[PRODUCT_NAME] - [MALL_NAME]` 규칙(스크린샷 3)이 통째로 무력화돼 있다.

### ② GA4 속성이 두 개 떠 있다

| 측정 ID | 출처 |
|---|---|
| `G-GZHFY596SS` | 우리 스킨 `moa/layout/head.html:2-10` — 우리가 분석해 온 속성(498152534) |
| `G-84HNK1MRBG` | 코드 직접입력 PC Head |
| `GTM-5W5PV3CD` | 코드 직접입력 PC Head/Body |

**지금 숫자가 2배로 잡히는 상태는 아니다** — 서로 다른 속성이라 각자 센다.
(498152534: page_view 93,707 / 세션 57,962 = 1.6배, 정상 범위)

다만 `gtag('event', ...)` 는 기본적으로 **페이지에 설정된 모든 측정ID로 뿌린다.**
그래서 `ds/js/ga4.js` 는 모든 이벤트에 `send_to: 'G-GZHFY596SS'` 를 붙인다.
안 붙이면 우리 전자상거래 이벤트가 남의 속성까지 들어간다.

## 판단이 필요한 것 (대표님)

1. **`G-84HNK1MRBG` 이 누구 것인가?** 대행사 것이면 지우면 안 된다.
   GA4 계정 목록에서 이 측정ID를 가진 속성을 찾아보면 나온다.
2. **`GTM-5W5PV3CD` 안에 `G-GZHFY596SS` 로 보내는 태그가 있는가?**
   있으면 그때부터 우리 속성이 2배가 된다. GTM 미리보기로 확인해야 한다.
3. **첫 번째 `<title>` 은 빼는 게 맞다.** 페이지별 제목이 살아나야
   구글에서 "붓기파우더" 같은 키워드로 상품페이지가 잡힌다.
   (meta description/keywords 는 남겨도 무방 — `<title>` 만 문제다)
