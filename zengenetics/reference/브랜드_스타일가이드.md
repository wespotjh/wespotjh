# 젠제네틱스 브랜드·디자인 스타일 가이드 (v1 · 2026-09-06)

> **이 문서의 용도** — 브랜드 스토리를 새로 손볼 때, **지금 만들어 둔 틀에서 벗어나지 않게** 하기 위한 기준서다.
> ChatGPT 등 외부 협업자에게 이 문서를 통째로 전달한다. 여기 적히지 않은 것을 새로 만들지 않는다.

## 0. 먼저 — 절대 어기면 안 되는 것 7가지

1. **지어낸 숫자·후기 금지.** 없는 수치를 만들지 않는다. 숫자를 쓰면 **반드시 기간·기준·채널을 같이 적는다.**
2. **평점·리뷰 수를 본문에 쓰지 않는다.** 알파리뷰 앱이 채우는 자리만 비워 둔다. (대표님 2026-09-06)
3. **가격과 할인율을 직접 쓰지 않는다.** cafe24 상품등록 값이 들어오고, %는 스킨이 계산한다.
4. **"개발 1년" 같은 개발 기간 문구를 넣지 않는다.**
5. **'루틴'·'웰니스'는 쓴다.** (예전 금지어 규칙은 해제됨)
6. **심의는 신경 쓰지 않는다.** 대표님이 마지막에 한 번에 처리하신다. 심의를 이유로 문구를 깎지 않는다.
7. **제품 패키지를 AI로 그리지 않는다.** 실제 제품 이미지만 쓴다.

## 2. 목소리 (Voice) — 가장 중요한 부분

### 2-1. 기본 규칙

| 항목 | 규칙 | 예 |
|---|---|---|
| 어미 | **`~습니다` / `~입니다` 평서형.** 감탄·느낌표 쓰지 않는다 | "3초면 끝납니다." |
| 자칭 | **`저희`** (`우리` 아님) | "저희가 하는 일은" |
| 권유 | 명령형 대신 **`~하시면 됩니다` / `~하셔도 됩니다`** | "물에 타서 드셔도 됩니다." |
| 고객 호칭 | 보통 **생략**. `당신`은 클로징 한 곳에서만 | "당신의 하루에 맞는 루틴을 고르세요" |
| 문장 길이 | **짧게 끊는다.** 한 문장 한 정보. 접속사 최소 | "삼키지 않아도 되는 것. 물이 없어도 되는 것." |
| 이모지 | **쓰지 않는다** | — |
| 물음표 | 헤드라인엔 거의 안 쓴다. FAQ·선택 유도에만 | "오늘 하루, 어디가 제일 아쉬우셨나요." |

### 2-2. 이 브랜드 특유의 화법 — **부정으로 신뢰를 만든다**

젠제네틱스 카피의 핵심 기술은 **"무엇을 안 했는지"를 먼저 말하는 것**이다. 이 패턴을 유지해야 한다.

```
감으로 정하지 않았습니다. 기준을 먼저 세우고 거기에 맞춘 숫자입니다.
그다음에 한 일은 빼는 일이었습니다.
투자는 받지 않았습니다. 팔아서 만들고, 남으면 또 만듭니다. 그게 전부입니다.
과장해서 팔면 두 번째 주문이 없으니 과장할 수도 없습니다.
셋 다 극적인 일은 하지 않습니다.
한 포로 하루가 바뀌지는 않습니다. 다만 한 달의 루틴은 바뀝니다.
```

→ **자랑을 자랑으로 하지 않는다.** 제약·한계·안 한 일을 먼저 말하고, 그 뒤에 사실을 놓는다.

### 2-3. 헤드라인 작법

- **두 줄로 끊는다.** 줄바꿈 위치가 의미 단위가 되게.
  ```
  몸이 못 만드는 것을
  매일 채웁니다
  ```
  ```
  비우는 만큼
  채웁니다
  ```
- **동사로 끝낸다.** 명사형 나열("최고의 미네랄 솔루션") 금지.
- 챕터 헤드라인은 **주장이 아니라 사실 서술**이다. "최고", "혁신", "1등" 같은 형용사를 쓰지 않는다.

### 2-4. 쓰지 않는 말 (블랙리스트)

`혁신` `최고` `놀라운` `기적` `완벽한 해답` `단 하나의` `~하세요!(느낌표 명령)`
`드디어` `역대급` `믿을 수 없는` `압도적` `초특가` `지금 바로!`
과장 부사(`무려`, `엄청`), 이모지, 물결표 남발(`~~`), 영어 남발.

### 2-5. 실제 문장 견본 (이 톤을 유지하라)

**여는 글**
> 웰니스는 무언가를 더 얹는 일이 아니라고 생각합니다. **하루에서 어긋난 것이 제자리로 돌아오는 일**에 가깝습니다.

**형태 (Chapter 02)**
> 제품을 만들기 전에 제일 많이 들은 말이 그거였습니다. 좋은 건 아는데 못 먹겠다고요. 큰 알약을 아침마다 세 알씩 삼키는 일은 생각보다 오래 못 갑니다.

**비움과 채움 (Chapter 06)**
> 하루는 몸에 자국을 남깁니다. 짜게 먹은 날은 몸이 무겁습니다. 오래 앉아 있던 날은 다리가 뻐근하고, 늦게 잔 날은 아침이 유난히 길게 느껴집니다. 특별한 일이 아니라 그냥 하루가 지나간 자리입니다.

**회사 (Chapter 08)**
> 매일 먹는 물건이라 그렇습니다. 한 번 사고 마는 물건이었다면 다른 회사가 됐을 겁니다.

### 3-2. 브랜드 스토리 (세리프 체계 — 여기만 다르다)

브랜드 스토리는 **의도적으로 명조(세리프)를 쓴다.** zen·명상 톤을 위한 결정이며 홈과 다른 것이 정상이다.

| 역할 | 폰트 | 적용 대상 |
|---|---|---|
| **헤드라인·리드** | **Noto Serif KR** (400/600/700) | 커버 H1/H2, 여는 글 리드, 챕터 H2, 브리딩 문장, 루틴 시간 라벨, 클로징 H2 |
| 본문 | IBM Plex Sans KR (300~600) | 단락 본문 |
| 라벨·숫자 | IBM Plex Mono | 챕터 인덱스, 큰 숫자(262.5 등), 국가 칩, 채널명, 캡션 |

세리프는 **큰 글자에만** 쓴다. 작은 본문에 세리프를 쓰지 않는다.

### 3-3. 조판 규칙 (공통)

- `letter-spacing`: 한글 헤드라인 **-2.5% ~ -1.5%**, 본문 -0.5%, 영문 라벨 **+14% ~ +26%**
- `line-height`: 헤드라인 1.28~1.40 / 본문 **1.70~1.85** (여유 있게)
- `word-break: keep-all` 필수 — 한국어 단어가 잘리면 안 된다
- 반응형은 `clamp()`로. 예: `clamp(26px,4vw,42px)`
- 숫자는 `font-variant-numeric: tabular-nums`

## 5. 레이아웃·컴포넌트

- **모바일 기준 390px**로 설계한다. 본문 최대폭 `520px`, 좌우 여백 `20px`.
- 섹션 구분은 **1px 헤어라인**(`--hair`)으로. 그림자·박스 남발 금지.
- 카드: `border-radius 13~16px` + `1px solid` 테두리 + 흰 배경. 그림자는 아주 옅게(`0 1px 2px rgba(16,32,64,.04)`).
- 칩/뱃지: `border-radius 999px`, `padding 5px 11px`, 12px 이하 글자.
- 버튼: 높이 46~54px, `border-radius 13px`(사각 CTA) 또는 `999px`(필형).
  기본 CTA는 **잉크색 배경 + 흰 글자**, 보조는 **흰 배경 + 잉크 테두리**.
- 영문 소제목(kicker)은 **mono · 대문자 · 넓은 자간 · 회색**으로 섹션 위에 올린다.
- 챕터 번호는 `01` `02` … 2자리로.

### 6-3. 상품페이지 (단품 3종 · 세트 3종 공통 골격)

```
01 상단 바 → 02 갤러리 → 03 상품 정보 → [세트만: 04 하루 루틴]
→ 수량 → 추가 상품 → 무료배송 진행바 → 합계
→ 상세 이미지(접힘 + "상세 정보 모두 보기")

→ 유의 문구 → 하단 고정 바(결제 예상 · 장바구니 · 구매하기)
```

- 상세 이미지는 **대표님이 만드신 것을 공홈 게시 순서 그대로** 넣는다. 재배열·삭제 금지.

## 10. 브랜드 스토리를 고칠 때 — GPT 체크리스트

작업 전 확인:
- [ ] 「하루를 고르게」라는 제목과 **커버 → 여는 글 → 01~10 → 클로징** 구조를 유지하는가
- [ ] 헤드라인이 **두 줄 · 동사 종결 · 사실 서술**인가
- [ ] `저희` / `~습니다` / `~하시면 됩니다` 화법을 지켰는가
- [ ] **부정으로 신뢰를 만드는 문장**이 챕터마다 최소 하나 있는가
- [ ] 숫자에 **기간·채널·기준**을 붙였는가
- [ ] 평점·리뷰 수를 본문에 직접 쓰지 않았는가
- [ ] 가격·할인율을 직접 쓰지 않았는가
- [ ] 제품 3종의 시간대·포 수·함량이 7절 팩트 시트와 일치하는가
- [ ] `Reset(칼륨) / Recharge(비타민B) / Recover(마그네슘)` 매핑을 지켰는가
- [ ] 블랙리스트 단어를 쓰지 않았는가
- [ ] 세리프는 큰 글자에만, 본문은 고딕인가
- [ ] 한 화면에 제품 액센트가 하나인가

**바꿔도 되는 것** — 챕터 안의 문장, 사진 선택, 챕터 순서(01·02는 고정 권장), 인터루드 제목.
**바꾸면 안 되는 것** — 브랜드 명제, Reset/Recharge/Recover 매핑, 제품 팩트, 폰트·색 토큰, 화법.
