# 🔴 SEO 긴급 수정 — `<title>` 과 canonical 중복 (2026-09-06)

라이브 소스 실측 + 브라우저 실험으로 확인. **아직 안 고쳤다 — 대표님이 관리자에서 지우셔야 한다.**

## 무엇이 문제인가

모든 페이지의 `<head>` 안에 `<title>` 이 **두 개**, `<link rel="canonical">` 이 **두 개** 있다.

```
상품페이지(칼륨) — 라이브 실측
  @ 81,157   <title>젠제네틱스｜건강한 파우더리 데일리 루틴</title>          ← 코드 직접입력
  @ 81,479   <link rel="canonical" href="https://zengenetics.co.kr/">        ← 코드 직접입력
  @ 81,795   <link rel="canonical" href=".../product/젠제네틱스-포타슘-칼륨-20ea/11/" />
  @121,083   <title>젠제네틱스 포타슘 칼륨 (20ea) | 붓기 제거 · … | Zengenetics</title>
```

**둘 다 head 안이고, 먼저 나오는 쪽이 이긴다.**

### 브라우저로 실제 확인한 결과

| | 브라우저가 쓰는 제목 | canonical |
|---|---|---|
| 지금 | `젠제네틱스｜건강한 파우더리 데일리 루틴` | `zengenetics.co.kr/` **+** 상품 URL (2개 충돌) |
| 두 줄 지운 뒤 | `젠제네틱스 포타슘 칼륨 (20ea) \| 붓기 제거 · … \| Zengenetics` | 상품 URL 1개 |

### 왜 canonical 쪽이 더 급한가

상품페이지가 구글에 **"이 페이지는 사실 홈페이지다"** 라고 말하고 있다.
canonical 이 둘이면 구글은 보통 **둘 다 무시**하지만, 홈 쪽을 택하면
상품페이지가 색인에서 홈으로 합쳐진다. 어느 쪽이든 상품페이지가 검색에서 손해다.

`<title>` 쪽은 SEO 설정(관리자 › SEO › 주요 페이지 SEO 태그 › 상품상세)에
`[PRODUCT_NAME] - [MALL_NAME]` 로 잘 설정해 두신 게 통째로 무력화된 상태다.

## 어디서 고치나

**카페24 관리자 › 쇼핑몰 설정 › 검색엔진 최적화(SEO) › 고급설정 › 코드 직접입력 › `PC 쇼핑몰` 탭 › Head 영역**

⚠️ **모바일 쇼핑몰 탭이 아니다.** 반응형이라 PC 블록이 모바일에도 그대로 나간다.
(모바일 탭의 `<title>붓기제거 추천 ｜ …</title>` 은 아이폰 UA 로 받아봐도 **한 번도 안 나온다** — 죽은 코드다.)

## 지울 것 — 딱 3줄

**① 제목 (1줄)**
```html
<title>젠제네틱스｜건강한 파우더리 데일리 루틴</title>
```

**② canonical (2줄)**
```html
<!-- Canonical 설정 -->
<link rel="canonical" href="https://zengenetics.co.kr/">
```

## 건드리지 말 것

- `G-84HNK1MRBG` gtag 스니펫, `GTM-5W5PV3CD` — 누구 것인지 확인 전까지 그대로 둔다
- `<!-- SEO 메타 태그: … -->` 주석과 그 아래 `description` / `keywords`
  → 상품별 description 이 앞서서 이미 이기고 있다. 놔둬도 해가 없다.
- `facebook-domain-verification` — 메타 광고 도메인 인증이다. 지우면 안 된다.

## 순서

1. Head 영역 내용을 **통째로 복사해 메모장에 백업**
2. 위 3줄만 지우기
3. 저장하기
4. 확인: 상품페이지를 새로고침했을 때 **브라우저 탭 제목이 상품명으로** 바뀌면 성공
