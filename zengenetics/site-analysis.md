### ✅ 2. 브랜드 스토리/회사소개 페이지 존재 여부

- 리뷰 시스템은 카페24 기본 게시판이 아니라 **알파리뷰(AlphaReview) 위젯** (+ 동일 벤더 AlphaPush 인기상품 팝업). 제품 상세에서 확인되는 요소:

  - AI 요약 블록 "리뷰로 보는 활용 가이드" (사용자 유형/구매 이유/활용 방식 자동 요약)

- 그 외 서드파티: **인센토(incento) 친구초대/추천 위젯**, 카카오톡 채널 상담, GA4 ×2 + GTM + Meta Pixel.

### "Whole body" 섹션의 이미지 로테이트(회전) 연출 — 구현 방식

- 각 제품 카드의 미디어는 3D 렌더링이 아니라 **`<video muted playsinline loop>` 태그의 사전 렌더링(pre-rendered) 360° 턴테이블 영상**이다.
  - 예: `https://res.cloudinary.com/.../library/carousel/Seed_DS01_Jar_1080-web_hd_720p.mov` (Cloudinary가 브라우저별 코덱으로 자동 변환, 720p)
  - `poster` 속성으로 정지 프레임 이미지(f_auto,q_auto)를 깔아 로드 전/재생 전 상태를 커버.
- **스크롤 스크럽이 아님**: 스크롤 위치와 회전 각도는 연동되지 않는다. 페이지 로드 시 영상은 paused 상태였고, JS(호버/뷰포트 진입)로 `video.play()`를 호출해 루프 재생하는 방식. GSAP ScrollTrigger·WebGL·canvas 미사용(홈 기준 canvas 0개).
- **리뉴얼 적용 시사점:**
  - 동일한 "제품이 도는" 인상은 **제품 턴테이블 촬영/렌더 영상 1개 + `<video loop muted playsinline>`**로 저비용 구현 가능 — Three.js 실물 3D 없이도 Seed와 같은 질감이 나온다.
  - 스크롤에 따라 회전을 제어하고 싶으면(브랜드 문서의 시그니처 모션 방향) 같은 소스를 **이미지 시퀀스로 추출해 GSAP ScrollTrigger scrub**으로 프레임을 넘기는 방식이 정석 — Seed보다 한 단계 나아간 연출이 된다.
  - Seed의 진짜 강점은 회전 자체보다 **"섹션마다 근거 하나씩"(기술→스토리→리뷰) 구조 + 절제된 카드 시스템** — 상세 본문이 이미 근거 서사를 갖춘 우리 상황과 잘 맞는다.

## 리뉴얼 관점 핵심 시사점 (요약)

1. **셀럽 의존도가 예상보다 높다** — 홈 첫 화면부터 배너·썸네일까지 약 15~20장이 설인아 컷. 노셀럽 전환 시 대체 비주얼(제품/성분/텍스처 촬영)이 대량 필요.
2. **브랜드 스토리 페이지가 사실상 없고, about.html에 타 브랜드 더미 문구가 방치** — 신규 제작 필수이자 빠른 수정 대상.
3. **근거 서사는 이미 상세페이지에 있다** — 함량(525mg)·원료(독일 Jungbunzlauer)·제조(콜마비앤에이치)·HACCP·올리브영/쿠팡 1위·재구매율 92%가 확보된 상태. 웹 네이티브로 옮기기만 하면 됨.
4. **신뢰 자산이 서드파티에 있다** — 알파리뷰(리뷰 5만+건 합산)·인센토·카카오채널. 스킨 전면 교체 시 위젯 연동 승계가 리스크 포인트.
5. **Seed의 회전 연출은 사전 렌더 턴테이블 영상** — 실물 3D 불필요, 영상 1개면 재현 가능. 스크롤 스크럽으로 업그레이드하면 시그니처 모션 방향과 합치.
