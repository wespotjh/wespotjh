## 5. 3D 렌더 아카이브 (2026-09-03 확보)

- 구조: **3제품 × {stick 36장, box20_turn 36장, box20_open 24장, day6_turn 36장, day6_open 24장} = 468장**
- 900×900 투명 PNG (리포 보관본은 시각적 무손실 8bit 변환, 원본 16bit는 드라이브)
- 턴테이블 36장 = 정확히 10°/장. **frame_0001=정면, 0019=뒷면, 0010/0028=측면**
- 포 실측: 정면 710×165px(비율 4.3:1), 측면 최대 두께 44px → **두께 = 폭의 27%** (통통한 렌즈 단면)
- `manifest.tsv` = 드라이브 file id + 바이트 (원본 재다운로드용; 드라이브 링크 공유는 대표님이 다시 잠갔을 수 있음)

## 6. 홈 히어로 현재 상태 (v 최종)

컨셉: 레퍼런스(NOIR VISION 선글라스 릴) 스타일 — 자이언트 타이포 + 씬별 색 세계 + 스펙 칩 + 스크롤 내러티브 "하루(아침→낮→저녁→밤)"

- **스크롤 타임라인**: 인트로(하루, 요가, 제품 없음) 0–.08 → MORNING(사과, 비타민B) .08–.26 → 3PM 인터루드(회의 사진) .30–.44 → EVENING(차 안 퇴근길, 칼륨) .44–.60 → NIGHT(은하수+별똥별, 마그네슘) .64–.80 → ALL DAY 피날레(만세 실루엣, 3종+가격 카드) .84+
- **배경**: 실사 6장 크로스페이드 + JS 그레이드(rgba 0.52/0.26/0.8)
- **태양/달**: DOM 렌더링 (CSS radial-gradient / 2D 캔버스 초승달) — WebGL 저알파가 iOS에서 무지개 노이즈로 깨져서 이동. 3D 좌표를 매 프레임 투영(placeSky). 레이어: 사진(1)<그레이드(2)<태양·달(3)<자이언트 워드(5)<WebGL(10)
- **포(제품)**: 렌더 앞면 텍스처를 **자체 파우치 지오메트리**(렌즈 단면 sqrt(1-u⁴), 두께=폭 27%, 상하 씰 테이퍼)에 매핑. 세워진 채 **세로축 회전** `rotation.y = t*0.12 + p*6π + mouse`
- **앞면 캐러셀 (대표님 아이디어)**: 뒷면 디자인은 어디에도 안 씀. 카메라 반대편으로 돌아간 면을 현재 비트 제품의 앞면으로 몰래 교체 → 반 바퀴마다 항상 앞면. 비트 시작(q<0.04)·로드 직후(t<0.6s)엔 강제 동기화
- **다이나믹**: 속도감이 아니라 **프레이밍**으로 (대표님 피드백 "조잡하면 안 됨") — 비트별 좌우 오프셋(0.45/0.75), 이브닝 대각 기울기, 나이트 로우앵글, 비트 중간 줌(camera.z 9.4−zi·2.1)
- **피날레**: 미니 포 2종(같은 파우치 지오메트리) 자전하며 등장, 가루 파티클 3줄기
- **카드 3종**: 실제 렌더 크롭(세로), rotateY 스핀, 양면 모두 앞면
- **모바일**: 자이언트 워드 16.5vw(잘림 방지), 뷰포트 390×844 기준 QA

### 대표님 확정 사항 (되돌리지 말 것)
1. 회전은 기존 속도 유지, 다이나믹은 프레이밍으로만 (빠른 스핀+웜블 = "조잡" 반려)
2. 인트로 "하루"에는 제품 없음 (MORNING부터 등장)
3. 나무 테이블 삭제 (배경 가림)
4. 모닝 이미지 = 사과 (새는 "뜬금포" 반려)
5. 포는 세로로 서서 세로축 회전 (가로 눕힘 반려, 앞뒤 텀블링 반려)
6. 뒷면 디자인 노출 금지 — 앞면 캐러셀
7. 실사 확정: dawn-04(요가)/morning7-06(사과)/noon3-01(회의)/evening4-01(차안 석양)/night-04(은하수)/allday6-03(만세)
