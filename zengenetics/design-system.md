## 컬러 시스템

| 역할 | 값 | 비고 |
|---|---|---|
| 브랜드 네이비 | 로열블루 계열 (#1E3A8A~#2447A9 근사) | 로고, Proven 섹션 배경, 키워드 강조 |
| 바탕 | 화이트/라이트 그레이 | 상세 본문은 밝은 화이트 기조 (네이비 배경은 포인트 섹션만) |
| **칼륨 액센트** | **오렌지** (#F97316 근사) | 키워드 하이라이트, K 뱃지, 제품 무대 배경(오렌지 그라데이션) |
| **비타민B 액센트** | **핑크/마젠타** (#E11D48 근사) | 동일 용법, B+ 뱃지 |
| **마그네슘 액센트** | 미정 (작업 중 — 확인 필요) | |
| 보조 그린 | 라임그린 | 525mg 숫자, 리뷰 뱃지 등 부분 사용 |

- 제품별 액센트 1색 + 네이비 + 화이트가 기본 문법. 본문 키워드는 액센트/네이비 볼드로 하이라이트.
- ⚠ 홈 프로토타입의 제품 컬러(칼륨=블루, 비타민B=골드, 마그네슘=샌드)는 **실제 제품 액센트와 불일치** → 홈을 칼륨=오렌지, 비타민B=핑크, 마그네슘=확정 후 반영으로 교체 필요.

## 타이포그래피
- 전체 **볼드 고딕(프리텐다드 계열) 단일 체계**. 세리프 없음.
- 섹션 라벨은 영문 회색 소제목: Check List / The Culprit(범인은) / The Answer / Point 01·02·03 / Summary / Proven / Q&A / Your Routine
- ⚠ 홈 프로토타입은 Noto Serif KR 헤드라인 사용 중 → 상세와 통일하려면 고딕 볼드로 교체 검토 (대표 결정 필요).

## 페이지 구조 템플릿 (두 상세 공통 — 마그네슘도 동일 틀 권장)
1. 공식 판매처 안내 (네이비 카드 + 홀로그램 씰)
2. 무드 히어로 — 라이프스타일 실사 + "Reset · Recharge · Recover" + 시간대별 카피 (칼륨=일몰 산, 비컴=아침 침실 기지개)
3. Check List — 공감 증상 (아이콘 카드)
4. 원인 서사 — 문제 정의 (칼륨=범인은 나트륨+3.3배 차트 / 비컴=왜 피곤한걸까+전환과정)
5. 원리 시각화 — 3D 렌더 일러스트 (칼륨=피부층 수분, 비컴=유리볼 구슬 은유) + 하단 범례 + "*해당 내용은 원료에 대한 설명입니다" 면책 문구
6. The Answer — 제품 실사 (액센트 그라데이션 배경) + 소구 뱃지 2개
7. Point 01~03 — 원료(독일 국기+인증 6종 그리드) / 3초 섭취(가루 낙하 컷) / 설계(FDA 단일 등)
8. Summary — 화이트 카드 3장
9. Proven — 네이비 배경: 올리브영·쿠팡 1위(각주), 92%, 4.9 + 후기 카드(연령·직업 표기)
10. Q&A 3문답 (이뇨제 질문 포함)
11. Your Routine — 타입 A/B + 시간 칩
12. 클로징 — 실사 패키지 + 네이비 CTA 필
13. 법정 제품정보 고시 + 영양정보 표

## 규제·표기 주의 (마그네슘 제작 시)
- **칼륨 = 당류가공품** (일반식품): 기능성 표현 불가 → 원료 설명 프레임 + "*해당 내용은 원료에 대한 설명입니다" 면책 필수. 자일리톨 10% 설사 고지 있음.
- **비타민B = 건강기능식품** (GMP 마크): B1/B2/B6/B12 고시형 기능성 문구 사용 가능 ("탄수화물과 에너지 대사에 필요" 등).
- 마그네슘이 어느 식품유형인지에 따라 카피 수위가 달라짐 — 제작 전 확인.
- 순위 표기는 반드시 기간·기준 각주 (올리브영 2026.03.22 09~10시, 쿠팡 2026.07.27~08.25).
