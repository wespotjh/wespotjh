## 1-3. 작업 규칙

- **새 `!important` 0개.** 래퍼 클래스(`.zg-detail`/`.zg-home`/`.zgbs`)로 구체도를 올려 이긴다
- **가격을 계산하지 마라.** 화면 금액은 `#totalPrice .total strong`(없으면 `em`)에서 읽는다. `(N개)` 꼬리 제거 필요
- **HTML 주석 안에 `{$` 를 쓰지 마라** — 카페24는 주석 안 변수도 치환한다(라이브 증거: 주석 속 `{$review_count}` 가 `413` 으로 박혀 나옴)
- **주석에 내부 인명·판정용어를 쓰지 마라** — 공개 소스에 나간다
- `<!--@css()-->` / `<!--@js()-->` 를 써라. 생 `<link>`/`<script src>` + 절대경로는 404 난다
- `ds/js/ga4.js` · `ds/js/zg-ga4.js` 는 **수정 금지**(변경하려면 대표님 승인 + 주문서 2페이지 재붙여넣기 필요)
- **제출 후 파일 편집 금지.** 이 규칙이 이 프로젝트에서 **4번 깨졌고** 그때마다 검수 도장이 이전 판에 찍혔다

# 7. 이 프로젝트에서 실제로 났던 사고 — 반드시 읽어라

같은 실수를 반복하지 않기 위해 남긴다. **전부 실제로 일어났다.**

1. **카페24는 HTML 주석 안의 `{$변수}`도 치환한다.** 증거: 라이브에 주석 속 `{$review_count}` 가 `413` 으로 박혀 나온다
2. **카페24는 접속 기기(UA)에 따라 수량 행을 두 종류로 만든다.** iPhone 은 `.quantity` 래퍼가 **없다**. 그래서 CSS 7블록이 모바일에서 아무 데도 안 걸렸다
3. **카페24 지연로더는 IntersectionObserver 다.** `overflow:hidden` 으로 잘린 이미지는 **영원히 안 뜬다.** 상세 이미지 12장이 죽어 크롤러 입장에서 상품설명이 통째로 사라질 뻔했다
4. **`scroll` 이벤트를 쏘는 완화책은 무효다** — IO 는 scroll 을 구독하지 않는다
5. **조사서 문구를 그대로 조건으로 옮기면 안 된다.** "옵션 select 없음" 조건에 **판매 상품 60·61·62 가 같이 걸려** 금액 줄이 죽었다(제출 전 자진 발견)
6. **집합을 세지 않고 대표 사례로 결론내는 사고가 3번 났다.** → 규칙: **판별식을 만들면 전수 집합에 돌려 참·거짓 양쪽 개수를 세고 조사서의 기대 집합과 대조한다**
7. **제출 후 파일을 고쳐 검수 도장이 이전 판에 찍힌 일이 4번.** → 하네스 `Z` 스위트로 자동 감지
8. **전제가 틀렸다: 상품은 9종이 아니라 13종이다** (60·34·91·93 누락 발견)
9. **폴더를 만들면 카페24 편집기에서 지울 수 없다.** `ga4.js` 폴더가 남아 파일명을 `zg-ga4.js` 로 우회했다. **[폴더추가] 말고 [화면추가]를 쓰라고 안내하라**
10. **프로토타입이 지어낸 문구가 있었다** — "2박스 이상은 금액 상관없이 무료배송"은 **사실이 아니었고** 전수 삭제했다
