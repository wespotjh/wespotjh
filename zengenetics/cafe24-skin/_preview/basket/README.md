**바꾼 것 — CSS 한 파일뿐**
- 새 파일 `ds/css/basket.css`
- `order/basket.html` 에 **`<!--@css(/ds/css/basket.css)-->` 한 줄만 추가** (23행)

**안 바꾼 것**
- `module="Order_*"` / `{$변수}` / `onclick="{$action_*}"` — 전부 원본 그대로
- 네이버 체크아웃 `{$naver_checkout_button_id}`, 결제앱 `{$app_payment_button_box_id}` 자리
- 옵션변경 레이어(`#ec-basketOptionModifyLayer`) 구조
- 7개 배송유형 반복 영역(기본/업체기본/해외/개별/무이자 3종) 구조

## 작업하며 걸렸던 것 (다음 사람 참고)

1. **수량 −/+ 가 카드 모서리로 튀었다.** 스킨은 `.ec-base-qty a:before/:after` 를 `position:absolute`
   로 그리는데, 내가 `.ec-base-qty` 를 `position:static` 으로 바꾸면서 기준점이 카드로 올라갔다.
   → `.ec-base-qty` 는 `position:relative` 로 두고, 대신 그 조각들을 끄고 SVG 배경으로 교체.
2. **삭제 버튼이 X 가 아니라 + 로 보였다.** 스킨은 `+` 를 그린 뒤 `.btnDelete` 자체를 45도 돌려
   X 를 만든다. 여기서 조각을 또 45도 돌리면 90도가 되어 다시 `+` 가 된다.
   → **조각은 돌리지 말고** 위치·크기·색만 바꾼다.
3. `basketPackage.css` 규칙은 대부분 `.xans-order-basketpackage` 아래에 있다. 이 클래스는
   cafe24 가 렌더할 때 붙이므로 **프리뷰에는 없다.** 라이브에서는 그 규칙과 우선순위가 겹칠 수 있어
   실제 적용 전에 한 번 더 확인이 필요하다.
