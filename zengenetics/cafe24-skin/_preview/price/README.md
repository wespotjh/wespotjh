## 무엇을 고쳤나

`ds/css/price.css` **한 파일만** 교체했다.
- `ds/html/price.html` — 안 건드림
- `ds/js/price-config.js` — 안 건드림 (색·아이콘·쿠폰금액은 여기서 옴)
- `ds/js/detail.js` — 안 건드림 (DOM 을 그리는 주체)

즉 **모아 스킨의 동작·플러그인 훅·cafe24 변수는 전부 그대로**고, 겉모습만 우리 것이 된다.

## 대표님 결정이 필요한 2건 (둘 다 `price-config.js` 한 줄짜리)

1. **최대 혜택가 색** — 지금은 `#ff0000` 순수 빨강이다. 우리 브랜드 네이비(`#1E3A8A`)로 바꾸면
   `compare.png` 의 **제안 B** 가 된다. CSS 가 아니라 config 값이라 대표님 결정 후 바꾼다.
2. **플친 쿠폰 `20,100원`** — 회원 쿠폰은 2,000원인데 플친만 20,100원이라 최종가가 17,800원이 된다.
   의도된 값이면 그대로 두고, `2,100`·`2,010` 오타면 한 자리 고치면 된다.
