그건 아무리 다듬어도 저 수준에 못 간다. 다른 재료로 만든 것이다.

## 엔진이 지키는 것

- **프레임 게이트** — 준비 안 된 프레임은 절대 그리지 않는다. 가장 가까운 준비된 프레임으로 대체 (빈 화면 0)
- **진행률 분모 = 트랙 − 스테이지** — sticky 에서 실제 연출에 쓰이는 거리. 트랙 높이로 나누면 어긋난다
- **`100svh`** — iOS 주소창이 차지하는 높이 대응
- **자막 톤 반전** — 장마다 배경이 밝음/어둠으로 뒤집히므로 자막 색과 스크림도 따라간다
- **되감기** — 진행률이 스크롤 위치의 순수 함수라 올리면 그대로 되돌아간다
